Controllability, observability and minimality

Which states can the inputs reach, and at what cost, and which initial states can the output record reveal? Each question concerns one linear map, from input signals to the final state or from the initial state to the output, and is answered by a rank test, a Gramian and the Popov–Belevitch–Hautus (PBH) eigenvector test. Together the answers locate the part of a realization that the transfer function describes: the Kalman decomposition.

Reachability is a range question

Given $\dot x = Ax + Bu$, an initial state $x_0$, a horizon $t_f > 0$ and a target $x_f$, decide whether some input steers the state from $x_0$ to $x_f$ at time $t_f$.

$A \in \R^{n\times n}$ and $B \in \R^{n\times m}$ are real constant matrices ($\R$ denotes the real numbers). Inputs are square-integrable, $u \in L^2([0, t_f]; \R^m)$, meaning measurable with $\int_0^{t_f}\norm{u(t)}^2\,\dd t < \infty$ ($\norm{\cdot}$ the Euclidean norm); this is a Hilbert space with inner product $\inner{u}{v} = \int_0^{t_f}v(t)^\T u(t)\,\dd t$, where $^\T$ denotes transpose (the standard spaces, chapter 5). By variation of constants (chapter 8),

$$x(t_f) = e^{At_f}x_0 + \Psi_{t_f}u,\qquad \Psi_{t_f}u = \int_0^{t_f}e^{A(t_f - \tau)}Bu(\tau)\,\dd\tau,$$

where $e^{At}$ is the matrix exponential and $\Psi_{t_f}: L^2([0, t_f]; \R^m) \to \R^n$ is a linear map, the input-to-state map; it is bounded ().

By the displayed formula, an input $u$ steers $x_0$ to $x_f$ at time $t_f$ exactly when $\Psi_{t_f}u = x_f - e^{At_f}x_0$, so steering is possible exactly when $x_f - e^{At_f}x_0 \in \Range(\Psi_{t_f})$, the range of $\Psi_{t_f}$. The goal is a finite test for this range that does not mention the infinite-dimensional input space, and a measure of how hard each direction is to reach.

A state $x$ is reachable at time $t_f$ if $x \in \Range(\Psi_{t_f})$, that is, if some input steers $0$ to $x$ in time $t_f$. The pair $(A, B)$ is controllable if every state can be steered to every other state in some finite time.

The definition lets the time depend on the two states, while reachability starts from the origin only. In continuous time the invertibility of $e^{At_f}$ makes these questions one, at a single horizon:

Let $A \in \R^{n\times n}$, $B \in \R^{n\times m}$ and $t_f > 0$. The following are equivalent: (i) every state is reachable at time $t_f$, that is, $\Range(\Psi_{t_f}) = \R^n$; (ii) every state can be steered to $0$ at time $t_f$; (iii) every state can be steered to every other state at time $t_f$. Moreover, $(A, B)$ is controllable if and only if (i) holds for some $t_f > 0$.

Proof. (i) $\Rightarrow$ (iii): the vector $x_f - e^{At_f}x_0$ lies in $\Range(\Psi_{t_f}) = \R^n$ for all $x_0$ and $x_f$. (iii) $\Rightarrow$ (ii) is the case $x_f = 0$. (ii) $\Rightarrow$ (i): $-e^{At_f}x_0 \in \Range(\Psi_{t_f})$ for every $x_0$, and since $e^{At_f}$ is invertible these vectors fill $\R^n$. For the last claim, (iii) at one horizon gives controllability. Conversely, if $(A, B)$ is controllable, each standard basis vector $e_i$ is reachable at some time $t_i$. An input that reaches $x$ at time $t$ also reaches it at any later time $t'$ when it is delayed by $t' - t$ and preceded by $u = 0$, during which the state stays at $0$. With $t_f = \max_i t_i$, every $e_i$ therefore lies in the subspace $\Range(\Psi_{t_f})$, which is then $\R^n$.

In discrete time, steering to the origin and reaching from it differ. The scalar system $x_{k+1} = 0\cdot x_k + 0\cdot u_k$ sends every state to $0$ in one step, yet from $0$ it reaches no other state. The step (ii) $\Rightarrow$ (i) in the proof of used the invertibility of $e^{At_f}$, and its discrete-time counterpart, the factor $A^N$ multiplying $x_0$ after $N$ steps, is here $0$.

Simple and extreme cases. (i) $B = 0$: only $0$ is reachable. (ii) $n = 1$, $\dot x = ax + bu$: from $0$ the constant input $u = \gamma$ reaches $\gamma\,b\int_0^{t_f}e^{as}\,\dd s$, so every state is reachable when $b \neq 0$, and chapter 5 found the cheapest input, $u^*(t) \propto e^{a(t_f - t)}$. (iii) $A = \diag(\lambda_1, \lambda_2)$, the diagonal matrix with entries $\lambda_1, \lambda_2$, and $B = (1, 1)^\T$: each coordinate obeys $\dot x_i = \lambda_ix_i + u$, so from the origin $x_1(t_f) - x_2(t_f) = \int_0^{t_f}\big(e^{\lambda_1(t_f - \tau)} - e^{\lambda_2(t_f - \tau)}\big)u(\tau)\,\dd\tau$, which vanishes for every input when $\lambda_1 = \lambda_2$: two identical modes driven by one input move in lockstep, and only the diagonal is reachable (along it the system is the scalar one of (ii)). (iv) The double integrator $\ddot q = u$ with state $(q, \dot q)$: the input acts on the velocity alone, yet every position and velocity is reachable, because velocity integrates into position, as the Gramian of confirms.

The map $\Psi_{t_f}$ is bounded, its adjoint is $(\Psi_{t_f}^*v)(\tau) = B^\T e^{A^\T(t_f - \tau)}v$, and

$$\Range(\Psi_{t_f}) = \Range\big(W_c(t_f)\big),\qquad W_c(t_f) = \Psi_{t_f}\Psi_{t_f}^* = \int_0^{t_f}e^{At}BB^\T e^{A^\T t}\,\dd t .$$

The symmetric positive semidefinite matrix $W_c(t_f)$ is the controllability Gramian on the horizon $t_f$.

Proof. The norm $\norm{\Psi_{t_f}u}$ is at most $\int_0^{t_f}\norm{e^{A(t_f - \tau)}B}\,\norm{u(\tau)}\,\dd\tau$, with $\norm{e^{As}B}$ the spectral norm, and by the Cauchy–Schwarz inequality in $L^2$ this is at most $\big(\int_0^{t_f}\norm{e^{As}B}^2\,\dd s\big)^{1/2}\norm{u}$, so $\Psi_{t_f}$ is bounded. Next, $v^\T\Psi_{t_f}u = \int_0^{t_f}\big(B^\T e^{A^\T(t_f - \tau)}v\big)^\T u(\tau)\,\dd\tau = \inner{u}{\Psi_{t_f}^*v}$, and the substitution $t = t_f - \tau$ gives the formula for $\Psi_{t_f}\Psi_{t_f}^*$. Write $\Psi = \Psi_{t_f}$ and $W = \Psi\Psi^*$. Clearly $\Range(W) \subseteq \Range(\Psi)$. Conversely, $v \perp \Range(\Psi)$ if and only if $\Psi^*v = 0$, and $v^\T Wv = \norm{\Psi^*v}^2$ shows that the null spaces agree, $\Null(W) = \Null(\Psi^*)$. For the symmetric matrix $W$, $\Range(W) = \Null(W)^\perp$ (fundamental theorem of linear algebra, chapter 1), so both ranges have the same orthogonal complement in $\R^n$ and coincide.

The controllability matrix and Kalman's rank test

Probe (iii) failed because $B$ and $AB$ were parallel; probe (iv) succeeded because $B = (0, 1)^\T$ and $AB = (1, 0)^\T$ span the plane. Conjecture: the reachable subspace is spanned by the columns of $B, AB, A^2B, \dots$, and the horizon does not matter.

For every $t_f > 0$,

$$\Range(\Psi_{t_f}) = \Range(\mathcal C),\qquad \mathcal C = \begin{bmatrix}B & AB & A^2B & \cdots & A^{n-1}B\end{bmatrix} \in \R^{n\times nm} .$$

Hence $(A, B)$ is controllable if and only if $\rank\mathcal C = n$, and then every state is reachable in every positive time. $\mathcal C$ is the controllability matrix.

Proof. Compare orthogonal complements. By , $v \perp \Range(\Psi_{t_f})$ if and only if $\phi(t) = v^\T e^{At}B$ vanishes for all $t \in [0, t_f]$. If it does, its derivatives at $0$ vanish: $\phi^{(k)}(0) = v^\T A^kB = 0$ for all $k$, so $v \perp \Range(\mathcal C)$. Conversely, if $v^\T A^kB = 0$ for $k \le n - 1$, the Cayley–Hamilton theorem (chapter 3) writes every $A^k$ with $k \ge n$ as a combination of $I, A, \dots, A^{n-1}$, so $v^\T A^kB = 0$ for all $k$ and $\phi(t) = \sum_k \frac{t^k}{k!}v^\T A^kB = 0$. Since the range does not depend on $t_f$, turns it into the controllability statement.

$\Range(\mathcal C)$ is the smallest subspace that contains $\Range(B)$ and is invariant under $A$, that is, satisfies $AV \subseteq V$.

Proof. It contains $\Range(B)$, and it is $A$-invariant because $A$ maps the columns of $A^kB$ to those of $A^{k+1}B$, which for $k = n - 1$ lie in $\Range(\mathcal C)$ by Cayley–Hamilton. Every $A$-invariant subspace containing $\Range(B)$ contains every column of every $A^kB$.

Let $A \in \R^{n\times n}$ and $B \in \R^{n\times m}$. For $x_{k+1} = Ax_k + Bu_k$ with integer time $k \ge 0$ and every $N \ge 1$,

$$x_N = A^Nx_0 + \mathcal C_N\begin{bmatrix}u_{N-1}\\ \vdots\\ u_0\end{bmatrix},\qquad \mathcal C_N = \begin{bmatrix}B & AB & \cdots & A^{N-1}B\end{bmatrix},$$

a plain linear system for the stacked inputs. (i) The states reachable from $0$ in $N$ steps form the subspace $\Range(\mathcal C_N)$; these subspaces are nested, $\Range(\mathcal C_N) \subseteq \Range(\mathcal C_{N+1})$, and $\Range(\mathcal C_N) = \Range(\mathcal C)$ for every $N \ge n$. (ii) If $d = x_f - A^Nx_0 \in \Range(\mathcal C_N)$, the input sequence of least energy $\sum_{k=0}^{N-1}\norm{u_k}^2$ that steers $x_0$ to $x_f$ in $N$ steps is the stacked vector $\mathcal C_N^+d$, where $^+$ denotes the Moore–Penrose pseudoinverse; when $\mathcal C_N$ has full row rank, its energy is $d^\T(\mathcal C_N\mathcal C_N^\T)^{-1}d$.

Proof. The formula holds for $N = 1$, and $x_{N+1} = Ax_N + Bu_N$ multiplies each term $A^jBu_{N-1-j}$ by $A$ and adds $Bu_N$, which is the formula for $N + 1$. (i) $\mathcal C_{N+1}$ contains the columns of $\mathcal C_N$, and for $j \ge n$ the Cayley–Hamilton theorem (chapter 3) writes $A^jB$ as a combination of $B, AB, \dots, A^{n-1}B$, so the columns added after $N = n$ lie in $\Range(\mathcal C)$. (ii) The energy is the squared Euclidean norm of the stacked input, so this is the minimum-norm solution of a consistent linear system, which is the pseudoinverse solution (the pseudoinverse solves both problems, chapter 2). For full row rank, $\mathcal C_N^+ = \mathcal C_N^\T(\mathcal C_N\mathcal C_N^\T)^{-1}$, and the squared norm of $\mathcal C_N^+d$ is $d^\T(\mathcal C_N\mathcal C_N^\T)^{-1}d$.

Controllability is invariant (a) under a change of state coordinates, $(A, B) \mapsto (TAT^{-1}, TB)$ with $T$ invertible, and (b) under state feedback, $(A, B) \mapsto (A - BK, B)$ for any $K \in \R^{m\times n}$.

Proof. (a) The controllability matrix becomes $T\mathcal C$. (b) The substitution $u = -Kx + v$ turns each trajectory of $\dot x = (A - BK)x + Bv$ into a trajectory of $\dot x = Ax + Bu$ and back ($v = u + Kx$), so both systems reach the same states.

Feedback can move the controllable eigenvalues (pole placement, chapter 10), but by (b) it cannot make an uncontrollable pair controllable.

One input cannot control a repeated mode. For $A = \lambda I_2$, with $I_2$ the $2\times2$ identity, and any $b \in \R^2$, the controllability matrix $[b,\ \lambda b]$ has rank at most 1: from the origin the state stays on the line through $b$. shows why a second independent eigenvector demands a second independent input.

Gramians, minimum energy and the reachable ellipsoid

The rank test is binary. Among all inputs that reach a target, find the one of least energy, and measure how hard each direction of the state space is to reach.

Let $(A, B)$ be controllable and $t_f > 0$. Then $W_c(t_f) \succ 0$ (positive definite), and among all inputs that steer $x_0$ to $x_f$ at time $t_f$, the unique minimizer of the energy $E(u) = \int_0^{t_f}\norm{u(t)}^2\,\dd t$ is

$$u^*(t) = B^\T e^{A^\T(t_f - t)}\,W_c(t_f)^{-1}\,d,\qquad d = x_f - e^{At_f}x_0,$$

with energy $E(u^*) = d^\T W_c(t_f)^{-1}d$.

Proof. $W_c(t_f) \succ 0$ by and . The constraint is $\Psi u = d$ with $\Psi = \Psi_{t_f}$, a minimum-norm problem in a Hilbert space (minimum norm under linear constraints, chapter 5). Let $\alpha = W_c(t_f)^{-1}d$ and $u^* = \Psi^*\alpha$, which is feasible because $\Psi\Psi^*\alpha = d$. Every feasible $u$ equals $u^* + \tilde u$ with $\Psi\tilde u = 0$, and $\inner{\tilde u}{u^*} = \inner{\tilde u}{\Psi^*\alpha} = \alpha^\T\Psi\tilde u = 0$, so $\norm u^2 = \norm{u^*}^2 + \norm{\tilde u}^2$ (Pythagoras), which is smallest only at $\tilde u = 0$. Finally $\norm{u^*}^2 = \alpha^\T\Psi\Psi^*\alpha = d^\T W_c(t_f)^{-1}d$.

In the setting of , let $\eta(t) = e^{A^\T(t_f - t)}W_c(t_f)^{-1}d$ for $0 \le t \le t_f$. Then $\eta$ solves the adjoint equation $\dot\eta = -A^\T\eta$ with $\eta(t_f) = W_c(t_f)^{-1}d$, the optimal input is $u^*(t) = B^\T\eta(t)$, and the state along $u^*$ is

$$x(t) = e^{At}x_0 + W_c(t)\,\eta(t),\qquad 0 \le t \le t_f,$$

with $W_c(0) = 0$; at $t = t_f$ it equals $x_f$.

Proof. Differentiating gives $\dot\eta = -A^\T\eta$, and $u^* = B^\T\eta$ is the formula of . By variation of constants and $e^{A^\T(t_f - \tau)} = e^{A^\T(t - \tau)}e^{A^\T(t_f - t)}$,

$$x(t) = e^{At}x_0 + \int_0^t e^{A(t - \tau)}BB^\T e^{A^\T(t - \tau)}\,\dd\tau\;\eta(t),$$

and the substitution $s = t - \tau$ turns the integral into $W_c(t)$. At $t = t_f$, $W_c(t_f)\eta(t_f) = d$, so $x(t_f) = e^{At_f}x_0 + d = x_f$.

The optimal input is thus a combination of the modes of the adjoint equation run backward from $t_f$; up to a constant factor set by the sign convention and the normalization of the cost, $\eta$ is the costate of Pontryagin's maximum principle.

For $A = \begin{bmatrix}0 & 1\\ 0 & 0\end{bmatrix}$ and $B = \begin{bmatrix}0\\ 1\end{bmatrix}$, $e^{At}B = (t, 1)^\T$ and

$$W_c(t_f) = \int_0^{t_f}\begin{bmatrix}t^2 & t\\ t & 1\end{bmatrix}\dd t = \begin{bmatrix}t_f^3/3 & t_f^2/2\\ t_f^2/2 & t_f\end{bmatrix},\qquad \det W_c(t_f) = \frac{t_f^4}{12} .$$

A rest-to-rest move of unit length, from $(0, 0)$ to $(1, 0)$, has $d = (1, 0)^\T$ and $W_c(t_f)^{-1}d = (12/t_f^3,\ -6/t_f^2)^\T$, so the optimal input is the ramp $u^*(t) = \frac{6}{t_f^2}\big(1 - \frac{2t}{t_f}\big)$, accelerating and then braking, with energy $12/t_f^3$. Halving the time multiplies the energy by 8.

Let $t_f > 0$. (i) If $(A, B)$ is controllable, the set of states reachable from $0$ at time $t_f$ with energy at most 1 is the ellipsoid

$$\mathcal E(t_f) = \{x : x^\T W_c(t_f)^{-1}x \le 1\},$$

whose semi-axes are $\sqrt{\lambda_i}\,q_i$ for the eigenpairs $(\lambda_i, q_i)$ of $W_c(t_f)$, with unit eigenvectors $q_i$. Reaching $q_i$ costs energy $1/\lambda_i$. From $x_0$ the unit-energy reachable set is the translate $e^{At_f}x_0 + \mathcal E(t_f)$. (ii) In general, $x$ is reachable from $0$ at time $t_f$ if and only if $x \in \Range(W_c(t_f))$, and its least energy is then $x^\T W_c(t_f)^+x$; the set reachable with energy at most 1 is the ellipsoid $W_c(t_f)^{1/2}\{\xi : \norm\xi \le 1\}$, the image of the unit ball under the positive semidefinite square root of $W_c(t_f)$, which has no extent along $\Null(W_c(t_f))$ and is therefore flat when $(A, B)$ is uncontrollable. (iii) The set reachable from $0$ with energy at most 1 grows with $t_f$: the set for $t_1$ lies in the set for $t_2$ when $t_1 \le t_2$.

Proof

(i) By with $x_0 = 0$ and $d = x$, the least energy that reaches $x$ is $x^\T W_c(t_f)^{-1}x$; if some input of energy at most 1 reaches $x$, the minimizer does too, so the set is $\mathcal E(t_f)$. Writing $x = \sum_ic_iq_i$ gives $x^\T W_c(t_f)^{-1}x = \sum_ic_i^2/\lambda_i$, the ellipsoid with the stated semi-axes, and $x = q_i$ costs $1/\lambda_i$. From $x_0$, replace $x$ by $x - e^{At_f}x_0$.

(ii) Write $W = W_c(t_f)$, $\Psi = \Psi_{t_f}$ and $P = WW^+$, the orthogonal projector onto $\Range(W)$ (chapter 2). By the reachable states form $\Range(W)$. For $x \in \Range(W)$ the proof of goes through with $\alpha = W^+x$, which is feasible because $\Psi\Psi^*\alpha = Px = x$, and gives the least energy $\alpha^\T W\alpha = x^\T W^+x$. In an orthonormal eigenbasis of $W$ one reads off $\Range(W^{1/2}) = \Range(W)$, $W^{1/2}W^+W^{1/2} = W^{1/2}(W^{1/2})^+ = P$ and $\big((W^{1/2})^+\big)^2 = W^+$. So if $x = W^{1/2}\xi$ with $\norm\xi \le 1$, then $x \in \Range(W)$ and $x^\T W^+x = \norm{P\xi}^2 \le 1$. Conversely, if $x \in \Range(W)$ and $x^\T W^+x \le 1$, then $\xi = (W^{1/2})^+x$ satisfies $W^{1/2}\xi = Px = x$ and $\norm\xi^2 = x^\T W^+x \le 1$. The set therefore lies in $\Range(W)$, whose orthogonal complement is $\Null(W)$.

(iii) An input of energy at most 1 that reaches $x$ at time $t_1$, delayed by $t_2 - t_1$ and preceded by $u = 0$ as in the proof of , reaches $x$ at time $t_2$ with the same energy.

$W_c(t_1) \preceq W_c(t_2)$ for $t_1 \le t_2$, where $\preceq$ is the Loewner order ($X \preceq Y$ when $Y - X \succeq 0$). If $A$ is Hurwitz (all eigenvalues with negative real part), $W_c(t_f)$ increases to $W_c = \int_0^\infty e^{At}BB^\T e^{A^\T t}\,\dd t$, the unique solution of the Lyapunov equation

$$AW_c + W_cA^\T + BB^\T = 0,$$

and, if $(A, B)$ is controllable, $x^\T W_c^{-1}x$ is the infimum over all horizons of the energy needed to reach $x$ from $0$.

Proof. The integrand is positive semidefinite, so $W_c(t_2) - W_c(t_1) = \int_{t_1}^{t_2}e^{At}BB^\T e^{A^\T t}\,\dd t \succeq 0$. For Hurwitz $A$, $\norm{e^{At}} \le M e^{-\mu t}$ with constants $M$ and $\mu > 0$ (eigenvalue tests in continuous time, chapter 7), so the integral converges, and $AW_c + W_cA^\T = \int_0^\infty \frac{\dd}{\dd t}\big(e^{At}BB^\T e^{A^\T t}\big)\,\dd t = -BB^\T$. The solution is unique because the map $X \mapsto AX + XA^\T$ has the eigenvalues $\lambda_i + \lambda_j \neq 0$, where $\lambda_i$ are the eigenvalues of $A$ (the Lyapunov operator, chapter 7). Finally let $(A, B)$ be controllable. The least energy $x^\T W_c(t_f)^{-1}x$ to reach $x$ at time $t_f$ () does not increase with $t_f$, since an input can be delayed and preceded by $u = 0$ as in the proof of . As $t_f \to \infty$ it converges to $x^\T W_c^{-1}x$, because $W_c \succeq W_c(t_f) \succ 0$ makes $W_c$ invertible and inversion is continuous; and a nonincreasing function has its limit as its infimum.

Graded controllability. The Gramian turns the binary rank into a spectrum: its eigenvalues give the energy cost of each eigendirection (), and its trace, smallest eigenvalue and condition number summarize reach and cost (). A second reading replaces the energy budget by random forcing, the setting of the Kalman filter in chapter 11 ().

Let $t_f > 0$ and $W = W_c(t_f)$. (i) For a unit vector $q$, the squared extent along $q$ of the set reachable from $0$ at time $t_f$ with energy at most 1, that is, the largest value of $(q^\T x)^2$ on that set, is $q^\T Wq = \int_0^{t_f}\norm{B^\T e^{A^\T t}q}^2\,\dd t$. (ii) For $q$ uniformly distributed on the unit sphere, the average of $q^\T Wq$ is $\tr W/n$, with $\tr$ the trace. If $(A, B)$ is controllable and $W$ has largest and smallest eigenvalues $\lambda_{\max}$ and $\lambda_{\min}$, then moreover (iii) the worst case over unit-norm targets $x$ of the least energy $x^\T W^{-1}x$ needed to reach $x$ from $0$ is $\max_{\norm x = 1}x^\T W^{-1}x = 1/\lambda_{\min}$, attained at the unit eigenvectors for $\lambda_{\min}$, and (iv) the ratio of the longest to the shortest semi-axis of $\mathcal E(t_f)$ is $(\lambda_{\max}/\lambda_{\min})^{1/2}$, the square root of the condition number of $W$.

Proof. (i) By (ii) the set is $\{W^{1/2}\xi : \norm\xi \le 1\}$, and the Cauchy–Schwarz inequality gives $(q^\T W^{1/2}\xi)^2 \le \norm{W^{1/2}q}^2\norm\xi^2 \le q^\T Wq$, with equality at $\xi = W^{1/2}q/\norm{W^{1/2}q}$ (at any unit $\xi$ if $W^{1/2}q = 0$). The integral is the definition of $W$. (ii) Let $\mathbb E$ denote the expectation. Permuting the coordinates of $q$, or reversing the sign of one of them, is an orthogonal map and leaves the uniform distribution unchanged, so $\mathbb E[q_iq_j] = 0$ for $i \neq j$ and the $\mathbb E[q_i^2]$ are equal, hence equal to $\mathbb E\norm q^2/n = 1/n$. Therefore $\mathbb E[q^\T Wq] = \sum_{i,j}W_{ij}\,\mathbb E[q_iq_j] = \tr W/n$. (iii) The largest eigenvalue of $W^{-1}$ is $1/\lambda_{\min}$, and Rayleigh's theorem (chapter 4) gives the maximum and where it is attained. (iv) follows from the semi-axes $\sqrt{\lambda_i}\,q_i$ in (i).

Let $\beta$ be a standard $m$-dimensional Wiener process (Brownian motion), so that $u = \dd\beta/\dd t$ is, formally, white noise of unit intensity, and let $x(t_f) = \int_0^{t_f}e^{A(t_f - \tau)}B\,\dd\beta(\tau)$ be the resulting state at time $t_f$, started from $0$. Then $x(t_f)$ is Gaussian with mean $0$ and covariance $\mathbb E\big[x(t_f)x(t_f)^\T\big] = W_c(t_f)$, where $\mathbb E$ is expectation. If $(A, B)$ is controllable, the density of $x(t_f)$ is proportional to $\exp\big(-\tfrac12x^\T W_c(t_f)^{-1}x\big)$, so it is constant on the boundaries of the scaled ellipsoids $r\,\mathcal E(t_f)$, $r > 0$.

Proof sketch

The integrand is deterministic, so $x(t_f)$ is a Wiener integral, the mean-square limit of the sums $\sum_k e^{A(t_f - \tau_k)}B\,\big(\beta(\tau_{k+1}) - \beta(\tau_k)\big)$ over refining partitions $0 = \tau_0 < \tau_1 < \dots$ of $[0, t_f]$. The increments are independent Gaussian vectors with mean $0$ and covariance $(\tau_{k+1} - \tau_k)I$, so each sum is Gaussian with mean $0$, and its covariance $\sum_k e^{A(t_f - \tau_k)}BB^\T e^{A^\T(t_f - \tau_k)}(\tau_{k+1} - \tau_k)$ is a Riemann sum for $W_c(t_f)$. A mean-square limit of Gaussian vectors is Gaussian, and its covariance is the limit of their covariances (for these sums, the Itô isometry). A Gaussian vector with mean $0$ and invertible covariance $W$ has density proportional to $\exp(-\tfrac12x^\T W^{-1}x)$.

Wiener integrals and the Itô isometry: B. Øksendal, Stochastic Differential Equations, 6th ed. (Springer, 2003), ch. 3; limits of normal random vectors: appendix A.

Stability helps one task and hurts the other. For $\dot x = ax + bu$ with $a \neq 0$ and $b \neq 0$, $W_c(t_f) = b^2\big(e^{2at_f} - 1\big)/(2a)$. If $a < 0$, reaching $x_f$ from $0$ costs $x_f^2/W_c(t_f)$, which decreases to $2\abs a x_f^2/b^2$ as $t_f \to \infty$, because the leak must be fought to the end; steering $x_0$ to $0$ costs $e^{2at_f}x_0^2/W_c(t_f) \to 0$, because waiting does the work. If $a > 0$ the roles swap: reaching costs tend to $0$, since the instability amplifies a small push, while steering to $0$ costs tend to $2ax_0^2/b^2$.

A controllable system can be practically uncontrollable. For $A = \diag(-1, -2)$ and $B = (1, \eps)^\T$ with $\eps \neq 0$, the pair is controllable ($\det\mathcal C = -\eps$), and the Lyapunov equation, which for diagonal $A = \diag(\lambda_1, \lambda_2)$ reads $(\lambda_i + \lambda_j)(W_c)_{ij} + b_ib_j = 0$ entrywise with $b_i$ the entries of $B$, gives $(W_c)_{ij} = b_ib_j/(-\lambda_i - \lambda_j)$:

$$W_c = \begin{bmatrix}1/2 & \eps/3\\ \eps/3 & \eps^2/4\end{bmatrix},\qquad \det W_c = \frac{\eps^2}{72},\qquad e_2^\T W_c^{-1}e_2 = \frac{36}{\eps^2} .$$

Reaching $e_2 = (0, 1)^\T$ from $0$ costs at least $36/\eps^2$ at every horizon, the infimum of , which is $3.6\times10^5$ for $\eps = 0.01$ (for $e_1$ the infimum is 18 for every $\eps \neq 0$), although the rank test certifies controllability for every $\eps \neq 0$.

Modes: the Popov–Belevitch–Hautus test

Probe (iii) and suggest that controllability fails mode by mode. Find a test that names the mode the input cannot reach.

The following are equivalent:

  1. $(A, B)$ is controllable;
  2. $\rank\begin{bmatrix}\lambda I - A & B\end{bmatrix} = n$ for every $\lambda \in \C$, the complex numbers (it suffices to check the eigenvalues of $A$);
  3. no left eigenvector of $A$ is orthogonal to the columns of $B$: there are no $w \in \C^n \setminus \{0\}$ and $\lambda \in \C$ with $w^*A = \lambda w^*$ and $w^*B = 0$, where $w^*$ is the conjugate transpose.

Proof. (2 $\Leftrightarrow$ 3) The rank of the $n\times(n + m)$ matrix drops exactly when a nonzero row vector $w^*$ annihilates it, that is, $w^*A = \lambda w^*$ and $w^*B = 0$; for $\lambda$ outside the spectrum the block $\lambda I - A$ alone has rank $n$. (1 $\Rightarrow$ 3) If $w^*A = \lambda w^*$ and $w^*B = 0$, then $w^*A^kB = \lambda^kw^*B = 0$ for all $k$, so $w^*\mathcal C = 0$ and $\rank\mathcal C < n$. (3 $\Rightarrow$ 1) If $\rank\mathcal C < n$, the reachable subspace $V = \Range(\mathcal C)$ is a proper $A$-invariant subspace containing $\Range(B)$ (). Its orthogonal complement $V^\perp \neq \{0\}$ is $A^\T$-invariant: for $v \in V^\perp$ and $x \in V$, $(A^\T v)^\T x = v^\T Ax = 0$. Hence $A^\T$ has an eigenvector $w$ in the complexification of $V^\perp$, $A^\T w = \bar\lambda w$, which means $w^*A = \lambda w^*$; and $w \perp V \supseteq \Range(B)$ gives $w^*B = 0$.

An eigenvalue at which the rank drops is an uncontrollable eigenvalue. It survives every state feedback (uncontrollable modes are fixed, chapter 10): if $w^*A = \lambda w^*$ and $w^*B = 0$, then $w^*(A - BK) = \lambda w^*$ for every $K$, so $\lambda$ remains an eigenvalue of $A - BK$ with the same left eigenvector.

Modal reading. In eigenvector coordinates each mode obeys its own scalar equation, and the input enters mode $i$ only through the row $w_i^*B$; the PBH test then reads mode by mode ().

Let $A = V\Lambda V^{-1}$ be diagonalizable, with $\Lambda = \diag(\lambda_1, \dots, \lambda_n)$, eigenvectors $v_j$ (the columns of $V$) and $w_i^*$ the rows of $V^{-1}$. Then:

  1. each $w_i$ is a left eigenvector, $w_i^*A = \lambda_iw_i^*$, normalized so that $w_i^*v_j = 1$ for $i = j$ and $0$ otherwise, and the modal coordinates $z_i = w_i^*x$ of $\dot x = Ax + Bu$ obey the decoupled equations
    $$\dot z_i = \lambda_iz_i + w_i^*Bu ;$$
  2. $w_i^*B = 0$ if and only if $\Range(B)$ lies in the span of the other eigenvectors $v_j$, $j \neq i$, which is $A$-invariant; then $\lambda_i$ is an uncontrollable eigenvalue, and every state reachable from $0$ has $z_i = 0$;
  3. if the eigenvalues are distinct, $\lambda_i$ is uncontrollable if and only if $w_i^*B = 0$, so $(A, B)$ is controllable if and only if $w_i^*B \neq 0$ for every $i$.

Proof. (1) $V^{-1}A = \Lambda V^{-1}$ and $V^{-1}V = I$ give the eigenvector relation and the normalization, and $z = V^{-1}x$ obeys $\dot z = V^{-1}(Ax + Bu) = \Lambda z + V^{-1}Bu$. (2) The $n - 1$ independent vectors $v_j$, $j \neq i$, are annihilated by $w_i^*$, so they span the null space of $w_i^*$ in $\C^n$, and this span is $A$-invariant because each $v_j$ is an eigenvector. A left eigenvector with $w_i^*B = 0$ makes $\lambda_i$ uncontrollable by , and $\dot z_i = \lambda_iz_i$ with $z_i(0) = 0$ gives $z_i = 0$ for all time. (3) For a simple eigenvalue the left eigenvectors are the nonzero multiples of $w_i$, so condition 3 of fails at $\lambda_i$ exactly when $w_i^*B = 0$.

The norms $\norm{w_i^*B}$ computed with unit-norm $w_i$ are called modal controllabilities (for one input, $\abs{w_i^*b}$; the visual also divides by $\norm b$). With distinct eigenvalues they detect exactly zero, but they are not energies: in , Nearly repeated eigenvalues has both modal controllabilities equal to $0.71$, while the eigenvalues of $W_c(2)$ differ by a factor of about 1100, a nearly flat ellipse. The hypothesis of distinct eigenvalues in (3) is needed: for $A = I_2$ with $V = I_2$ and $b = (1, 1)^\T$, both numbers $w_i^*b$ equal 1, yet the pair is uncontrollable ().

If an eigenvalue $\lambda$ of $A$ has geometric multiplicity $g$ (that many independent eigenvectors), controllability requires $m \ge g$ inputs. In particular a single input never controls $A$ when some eigenvalue has two independent eigenvectors.

Proof. The column space of a matrix $[X\ \ Y]$ is the sum of the column spaces of $X$ and $Y$, so its rank is at most $\rank X + \rank Y$, and

$$\rank\begin{bmatrix}\lambda I - A & B\end{bmatrix} \le \rank(\lambda I - A) + \rank B \le (n - g) + m,$$

and the rank condition at $\lambda$ needs $m \ge g$.

The Jordan block $J = \begin{bmatrix}\lambda & 1\\ 0 & \lambda\end{bmatrix}$ has a single eigenvector, so one input can suffice. Its only left eigenvector is $w = e_2$ ($e_2^\T J = \lambda e_2^\T$), so $(J, b)$ is controllable if and only if $b_2 \neq 0$: the input enters the second state, which feeds the first. A chain is easier to drive than two identical uncoupled modes, though both have the eigenvalue $\lambda$ twice.

Observability and duality

For $\dot x = Ax + Bu$, $y = Cx + Du$ with the input known, reconstruct the initial state from the output on $[0, t_f]$.

Subtracting the known forced response (variation of constants, chapter 8) reduces the problem to $u = 0$, so the record is $y(t) = Ce^{At}x_0$ with $C \in \R^{p\times n}$. Define the state-to-output map $\Gamma_{t_f}: \R^n \to L^2([0, t_f]; \R^p)$, $(\Gamma_{t_f}x_0)(t) = Ce^{At}x_0$. Reconstruction is possible exactly when $\Gamma_{t_f}$ is injective: a null-space question.

The pair $(C, A)$ is observable if $\Null(\Gamma_{t_f}) = \{0\}$. The subspace $\Null(\Gamma_{t_f})$ of initial states that produce the zero output is the unobservable subspace. The observability matrix and the observability Gramian are

$$\mathcal O = \begin{bmatrix}C\\ CA\\ \vdots\\ CA^{n-1}\end{bmatrix} \in \R^{np\times n},\qquad W_o(t_f) = \Gamma_{t_f}^*\Gamma_{t_f} = \int_0^{t_f}e^{A^\T t}C^\T Ce^{At}\,\dd t .$$

For every $t_f > 0$, $\Null(\Gamma_{t_f}) = \Null(\mathcal O) = \Null\big(W_o(t_f)\big)$, and $\Null(\mathcal O)$ is the largest $A$-invariant subspace contained in $\Null(C)$. Hence $(C, A)$ is observable if and only if $\rank\mathcal O = n$, if and only if $W_o(t_f) \succ 0$, if and only if $\rank\begin{bmatrix}\lambda I - A\\ C\end{bmatrix} = n$ for every $\lambda \in \C$, that is, no eigenvector of $A$ lies in $\Null(C)$.

Proof. $Ce^{At}x_0 = 0$ on $[0, t_f]$ if and only if $CA^kx_0 = 0$ for all $k$, by the derivative and Cayley–Hamilton argument of ; and $x_0^\T W_o(t_f)x_0 = \int_0^{t_f}\norm{Ce^{At}x_0}^2\,\dd t$. The subspace $\Null(\mathcal O)$ lies in $\Null(C)$ and is $A$-invariant, by Cayley–Hamilton again; if $V \subseteq \Null(C)$ is $A$-invariant, then $CA^kx = 0$ for $x \in V$ and all $k$, so $V \subseteq \Null(\mathcal O)$. The rank condition follows from and .

$(C, A)$ is observable if and only if $(A^\T, C^\T)$ is controllable. More precisely, $\mathcal O(C, A) = \mathcal C(A^\T, C^\T)^\T$ and $W_o(t_f; C, A) = W_c(t_f; A^\T, C^\T)$.

Proof. Transposing the block rows $CA^k$ gives the block columns $(A^\T)^kC^\T$, and the Gramian integrands agree because $(e^{At})^\T = e^{A^\T t}$.

A realization of $G$ is minimal if no realization of $G$ has smaller order. Then:

  1. a realization is minimal if and only if it is controllable and observable;
  2. any two minimal realizations $(A, B, C, D)$ and $(A', B', C', D)$ are similar: there is a unique invertible $T$ with $A' = TAT^{-1}$, $B' = TB$, $C' = CT^{-1}$;
  3. for any realization of order $n$, the minimal order equals $\rank(\mathcal O\mathcal C)$, the rank of the block Hankel matrix $\big[CA^{i+j-2}B\big]_{i,j=1}^{n}$ of Markov parameters.
Proof

The $(i, j)$ block of $\mathcal O\mathcal C$ is $CA^{i+j-2}B$, a Markov parameter, so it depends only on $G$: Markov parameters are the coefficients of the expansion of $G$ at infinity (structure of the transfer function, chapter 8), and two such expansions that agree for all large $\abs s$ have the same coefficients. To compare realizations of different orders, use the $N\times N$ block Hankel matrix built from extended observability and controllability matrices with $N$ block rows and columns, $N$ the larger order.

(1) If a realization is not controllable and observable, produces the smaller realization $(A_{11}, B_1, C_1, D)$. Conversely, let $(A, B, C, D)$ of order $n$ be controllable and observable, and suppose a realization of order $n' < n$ exists. The $n\times n$ block Hankel matrices of the two coincide. For the first it is $\mathcal O\mathcal C$ with $\mathcal O$ of full column rank $n$ and $\mathcal C$ of full row rank $n$, so its rank is $n$; for the second it factors through $\R^{n'}$, so its rank is at most $n'$. This is a contradiction.

(2) Both realizations have order $n$ and $\mathcal O\mathcal C = \mathcal O'\mathcal C'$, and also $\mathcal OA\mathcal C = \mathcal O'A'\mathcal C'$ (blocks $CA^{i+j-1}B$). The first block column gives $TB = B'$. Next, $(\mathcal O - \mathcal O'T)\mathcal C = 0$ and $\mathcal C$ has full row rank, so $\mathcal O = \mathcal O'T$, whose first block row is $C = C'T$. Finally $\mathcal O'TA\mathcal C = \mathcal O'A'T\mathcal C$, and cancelling $\mathcal O'$ on the left and $\mathcal C$ on the right gives $TA = A'T$. Any such $T$ satisfies $T\mathcal C = \mathcal C'$, which determines it.

An eigenvalue $\lambda$ of $A$ with $\rank\begin{bmatrix}\lambda I - A\\ C\end{bmatrix} < n$ is an unobservable eigenvalue, and $(C, A)$ is detectable if every unobservable eigenvalue has negative real part.

Hence $(A, B)$ is stabilizable if and only if $A_{33}$ and $A_{44}$ are Hurwitz, and $(C, A)$ is detectable if and only if $A_{22}$ and $A_{44}$ are Hurwitz.

Proof. Both kinds of eigenvalue are unchanged by the change of coordinates. Grouping the parts as $(1, 2 \mid 3, 4)$ gives $\tilde A = \begin{bmatrix}A_{\rm c} & *\\ 0 & A_{\bar{\rm c}}\end{bmatrix}$ and $\tilde B = \begin{bmatrix}B_{\rm c}\\ 0\end{bmatrix}$, with $A_{\bar{\rm c}} = \begin{bmatrix}A_{33} & 0\\ A_{43} & A_{44}\end{bmatrix}$; the pair $(A_{\rm c}, B_{\rm c})$ is controllable, because from $0$ the coordinates $\tilde x_3, \tilde x_4$ stay zero, $(\tilde x_1, \tilde x_2)$ follows $(A_{\rm c}, B_{\rm c})$, and the states reachable from $0$ are exactly those with $\tilde x_3 = \tilde x_4 = 0$. If $w_{\bar{\rm c}}^*A_{\bar{\rm c}} = \lambda w_{\bar{\rm c}}^*$ with $w_{\bar{\rm c}} \neq 0$, then $w = (0, w_{\bar{\rm c}})$ is a left eigenvector of $\tilde A$ with $w^*\tilde B = 0$. Conversely, if $w = (w_{\rm c}, w_{\bar{\rm c}})$ is such a left eigenvector, its first block column gives $w_{\rm c}^*A_{\rm c} = \lambda w_{\rm c}^*$ and $w_{\rm c}^*B_{\rm c} = 0$, so $w_{\rm c} = 0$ by , and then $w_{\bar{\rm c}}^*A_{\bar{\rm c}} = \lambda w_{\bar{\rm c}}^*$. The eigenvalues of the block triangular $A_{\bar{\rm c}}$ are those of $A_{33}$ and $A_{44}$. The unobservable eigenvalues follow in the same way, with right eigenvectors, from the grouping $(1, 3 \mid 2, 4)$: there $\tilde A = \begin{bmatrix}A_{\rm o} & 0\\ * & A_{\bar{\rm o}}\end{bmatrix}$ and $\tilde C = [C_{\rm o}\ \ 0]$ with $A_{\bar{\rm o}} = \begin{bmatrix}A_{22} & A_{24}\\ 0 & A_{44}\end{bmatrix}$ and $(C_{\rm o}, A_{\rm o})$ observable, because with zero input $(\tilde x_1, \tilde x_3)$ follows $A_{\rm o}$ alone and determines $y$, and the unobservable states are exactly those with $\tilde x_1 = \tilde x_3 = 0$.

For a stabilizable and detectable single-input single-output realization, bounded-input bounded-output stability (chapter 8) is equivalent to internal stability, that is, to $A$ being Hurwitz.

Proof. The spectrum of $\tilde A$ is the union of the spectra of $A_{11}, \dots, A_{44}$: in the block order $3, 1, 4, 2$ the matrix is block lower triangular. The eigenvalues of $A_{11}$ are the poles of $G$ (), which all have negative real part exactly when the system is bounded-input bounded-output stable (the stability theorem for transfer functions, chapter 8), and stabilizability and detectability make $A_{22}$, $A_{33}$ and $A_{44}$ Hurwitz ().

Stabilizability is exactly what state feedback needs (chapter 10), and detectability what an observer needs (chapter 10). No linear controller, static or dynamic, can do without them:

Let $(A, B, C, D)$ be a realization, and close the loop with a controller $\dot x_K = A_Kx_K + B_Ky$, $u = C_Kx_K + D_Ky$ of any order, order $0$ being a static gain $u = D_Ky$, such that $I - D_KD$ is invertible (the loop is well posed). Every uncontrollable eigenvalue of $(A, B)$ and every unobservable eigenvalue of $(C, A)$ is an eigenvalue of the closed-loop state matrix. Hence, if $(A, B)$ is not stabilizable or $(C, A)$ is not detectable, no such controller makes the closed loop internally stable, that is, makes its state matrix Hurwitz.

Proof. Solving the loop equations gives $u = E(C_Kx_K + D_KCx)$ with $E = (I - D_KD)^{-1}$, and the closed-loop state $(x, x_K)$ obeys $\dot x = Ax + Bu$ and $\dot x_K = A_Kx_K + B_K(Cx + Du)$. If $Av = \lambda v$ and $Cv = 0$, the state $(v, 0)$ gives $u = 0$ and is mapped to $(\lambda v, 0)$, so $\lambda$ is a closed-loop eigenvalue. If $w^*A = \lambda w^*$ and $w^*B = 0$, the row vector $(w^*, 0)$ times the closed-loop matrix is $(w^*A, 0) = \lambda(w^*, 0)$, because $\dot x = Ax + Bu$ and $w^*B = 0$.

Graded controllability in large networks

In a network $\dot x = Ax + B_{\mathcal K}u$ with $n$ nodes, the inputs act on a set $\mathcal K = \{k_1, \dots, k_m\}$ of driver nodes through $B_{\mathcal K} = [e_{k_1}, \dots, e_{k_m}]$, where $e_k$ is the $k$-th standard basis vector. How many driver nodes are needed, and is the rank test the right question?

The rank test is generic, and therefore almost uninformative: almost every pair is controllable, even with a single input, and the same holds within every fixed pattern of nonzero entries that admits one controllable choice (). Structural controllability (Lin, 1974) characterizes such patterns by their graphs, and Liu, Slotine and Barabási (2011) used it to count the driver nodes that large networks need. Neither statement says anything about cost.

Let $n, m \ge 1$. (i) The uncontrollable pairs $(A, B) \in \R^{n\times n}\times\R^{n\times m}$ are the common zeros of the $n\times n$ minors of $\mathcal C$. They form a closed set with empty interior and Lebesgue measure zero, so the controllable pairs form an open dense set of full measure. (ii) Fix the entries of $A$ and $B$ that are allowed to be nonzero, the others being $0$. If some choice of the allowed entries gives a controllable pair, then the uncontrollable choices form a closed set with empty interior and measure zero in the space of allowed entries.

Proof. $\rank\mathcal C < n$ exactly when every $n\times n$ minor of $\mathcal C$ vanishes, and each minor is a polynomial in the entries of $A$ and $B$, so the uncontrollable set is closed. Some minor is not identically zero: for the shift $A$ with $Ae_j = e_{j+1}$ ($j < n$), $Ae_n = 0$, and $B$ with first column $e_1$, the columns $e_1, Ae_1, \dots, A^{n-1}e_1$ of $\mathcal C$ form the identity. The zero set of a polynomial that is not identically zero has measure zero (by induction on the number of variables and Fubini's theorem) and empty interior (a polynomial that vanishes on an open set has all its derivatives zero there, hence all its coefficients), and the uncontrollable set lies in such a zero set. (ii) is the same argument in the coordinates of the allowed entries, where the given controllable choice shows that some minor is not identically zero.

Take $n$ nodes on a line, $\dot x_i = -x_i + \tfrac12(x_{i-1} + x_{i+1})$ with missing neighbours omitted, and one input at node 1, $B = e_1$. The matrix $A$ is symmetric with the eigenvalues $-1 + \cos(k\pi/(n + 1))$, $k = 1, \dots, n$, all negative (the eigenvectors have the entries $\sin(jk\pi/(n + 1))$, $j = 1, \dots, n$), so it is stable. The input propagates down the chain: for $k < n$, $A^ke_1$ has its last nonzero entry, $2^{-k}$, in position $k + 1$, so $\mathcal C$ is upper triangular with nonzero diagonal, and the pair is controllable for every $n$. Let $A \in \R^{n\times n}$ be symmetric and Schur stable, that is, with spectral radius $\rho(A) < 1$, the largest modulus of an eigenvalue. Let $\mathcal K$ be a set of driver nodes, with $\abs{\mathcal K}$ elements, and let $W_N = \sum_{k=0}^{N-1}A^kB_{\mathcal K}B_{\mathcal K}^\T A^k$ be the $N$-step controllability Gramian of the discrete-time network $x_{k+1} = Ax_k + B_{\mathcal K}u_k$. For every horizon $N \ge 1$,

$$\lambda_{\min}(W_N) \le \frac{\rho(A)^{2(\lceil n/\abs{\mathcal K}\rceil - 1)}}{1 - \rho(A)^2},$$

where $\lceil\cdot\rceil$ rounds up. When $W_N \succ 0$, the least energy needed to reach the hardest unit-norm target from $0$ in $N$ steps is $\max_{\norm{x_f} = 1}x_f^\T W_N^{-1}x_f = 1/\lambda_{\min}(W_N)$, by with $W_N = \mathcal C_N\mathcal C_N^\T$. Hence if $\abs{\mathcal K}$ is held fixed and $\rho(A) \le \bar\rho$ for a constant $\bar\rho \in (0, 1)$ along a family of networks, this energy is at least $(1 - \bar\rho^2)\,\bar\rho^{-2(\lceil n/\abs{\mathcal K}\rceil - 1)}$, which grows exponentially with $n$.

The smallest complex perturbation that makes $(A, B)$ uncontrollable has size

$$\tau(A, B) = \min\big\{\norm{[E\ \ F]} : (A + E,\ B + F)\ \text{uncontrollable}\big\} = \min_{\lambda \in \C}\sigma_{\min}\big([A - \lambda I\ \ B]\big),$$

where $\norm{\cdot}$ is the spectral norm and $\sigma_{\min}$ the smallest ($n$-th) singular value. Moreover,

$$\sigma_{\min}\big([A - \lambda I\ \ B]\big) = \min_{w \in \C^n,\ \norm w = 1}\big(\norm{w^*(A - \lambda I)}^2 + \norm{w^*B}^2\big)^{1/2},$$

so for $\eps > 0$, $\tau(A, B) \le \eps$ if and only if some $\lambda \in \C$ and unit vector $w$ satisfy $\norm{w^*(A - \lambda I)}^2 + \norm{w^*B}^2 \le \eps^2$: an approximate left eigenvector nearly orthogonal to $\Range(B)$, an approximate form of the PBH test.

Proof. The PBH test and the Eckart–Young–Mirsky theorem were stated for real matrices; their proofs hold verbatim for complex ones, with $^*$ in place of $^\T$. For a matrix $M$ with $n$ rows and at least $n$ columns, $\sigma_{\min}(M)^2$ is the smallest eigenvalue of $MM^*$, which by Rayleigh's theorem (chapter 4) is $\min_{\norm w = 1}w^*MM^*w$, that is, $\min_{\norm w = 1}\norm{w^*M}^2$. With $\norm{w^*[X\ \ Y]}^2 = \norm{w^*X}^2 + \norm{w^*Y}^2$ this is the displayed identity, and it shows that $\sigma_{\min}([A - \lambda I\ \ B])$ is at least $\min_{\norm w = 1}\norm{w^*(A - \lambda I)}$, hence at least $\abs\lambda - \norm A$. If $(A + E, B + F)$ is uncontrollable, the PBH test gives a $\lambda$ with $\rank[A + E - \lambda I,\ B + F] < n$. This matrix differs from $[A - \lambda I,\ B]$ by $[E\ \ F]$, and the distance from a matrix to the matrices of lower rank is its smallest singular value (Eckart–Young–Mirsky, chapter 4), so $\norm{[E\ \ F]} \ge \sigma_{\min}([A - \lambda I\ \ B])$. Conversely, $\sigma_{\min}([A - \lambda I\ \ B])$ is continuous in $\lambda$ and, by the bound above, grows without bound as $\abs\lambda \to \infty$, so a minimizing $\lambda$ exists, and there the rank-one perturbation $-\sigma_{\min}u_nv_n^*$ built from the last singular pair $(u_n, v_n)$ makes the rank drop.

Gramian metrics ($\lambda_{\min}(W_c)$, $\tr W_c$, $\tr W_c^{-1}$, $\log\det W_c$) and the distance to uncontrollability answer different questions: the energy needed to reach states, and the robustness of the rank itself. Both are graded, and both are what claims about the controllability of biological networks, including brain networks (chapter 13), should rest on, rather than a rank. As a rule of thumb, a rank decided in floating point becomes unreliable once the condition numbers involved approach the reciprocal of machine epsilon, as for $W_c$ from $n = 12$ and for $\mathcal C$ at $n = 20$ in .

Self-check

  1. Is $(A, b)$ controllable for $A = \begin{bmatrix}1 & 1\\ 0 & 1\end{bmatrix}$ and $b = (1, 0)^\T$? For $b = (0, 1)^\T$? Answer with both the rank test and the PBH test.

    Answer

    $[b,\ Ab] = \begin{bmatrix}1 & 1\\ 0 & 0\end{bmatrix}$ has rank 1, so no; with $b = (0, 1)^\T$, $[b,\ Ab] = \begin{bmatrix}0 & 1\\ 1 & 1\end{bmatrix}$ has rank 2. PBH: the only left eigenvector is $e_2$, and $e_2^\T b$ is $0$ in the first case and $1$ in the second.

  2. The double integrator moves from rest at $0$ to rest at $1$ in time $t_f = 2$. What are the minimum energy and the peak input?

    Answer

    Energy $12/t_f^3 = 1.5$; the input $u^*(t) = \frac{6}{t_f^2}(1 - 2t/t_f)$ has peak magnitude $6/t_f^2 = 1.5$ at both ends.

  3. Show that state feedback can destroy observability. Hint: put $G(s) = (s + 1)/(s^2 + 5s + 6)$ in controllable canonical form and move a pole to $-1$.

    Answer

    $A = \begin{bmatrix}-5 & -6\\ 1 & 0\end{bmatrix}$, $B = e_1$, $C = (1, 1)$. With $K = (0, -2)$, $A - BK$ is the companion matrix of $s^2 + 5s + 4 = (s+1)(s+4)$, and state feedback leaves the numerator unchanged (state feedback does not move zeros, chapter 10), so the closed loop is $(s + 1)/\big((s+1)(s+4)\big)$: the mode $-1$ cancels. It is unobservable: $C(A - BK) = (-4, -4)$, so $\mathcal O$ has rank 1, and $v = (1, -1)^\T$ satisfies $Cv = 0$ and $(A - BK)v = -v$. Controllability survives (); observability need not.

  4. How many inputs does $A = \diag(-1, -1, -2)$ need? Is $B = [e_1 + e_3,\ e_2]$ enough?

    Answer

    At least two, since the eigenvalue $-1$ has geometric multiplicity 2 (). With this $B$: the left eigenvectors for $-1$ are $w = (\zeta_1, \zeta_2, 0) \neq 0$ with $w^*B = (\bar\zeta_1, \bar\zeta_2) \neq 0$, and for $-2$, $w = e_3$ with $e_3^\T B = (1, 0)$. By the pair is controllable.

  5. In a Kalman decomposition, $A_{22} = 1$ and every other diagonal block is Hurwitz. Is the realization stabilizable, detectable, bounded-input bounded-output stable? Can any output feedback stabilize it?

    Answer

    Stabilizable, since parts 3 and 4 are stable; not detectable, since part 2 is unobservable and unstable (); bounded-input bounded-output stable, since $G$ depends only on the Hurwitz block $A_{11}$ (). No output feedback can stabilize it (): for a static gain $K$ the unobservable subspace is invariant under $A + BKC$, on which $A + BKC$ acts as $A$, so the eigenvalue $1$ stays, and for dynamic controllers the same holds for the augmented system.
