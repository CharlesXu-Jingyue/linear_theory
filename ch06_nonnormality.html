Perturbation, non-normality and pseudospectra

A good numerical method returns the exact answer to a slightly different problem, so the useful question is how far answers move when the data move. For linear systems one number, the condition number, bounds that motion. For the eigenvalues of a non-normal matrix the answer can be enormous, and the same mechanism lets the solutions of a stable linear differential equation grow by large factors before they decay; pseudospectra and the numerical range see this, the spectrum does not.

Conditioning of linear systems

A system $Ax = b$, with $A \in \C^{n\times n}$ (a complex $n\times n$ matrix) invertible and $b \neq 0$, is solved from data that carry errors: a measured right-hand side, rounded entries, a model that is only approximately right. Bound the error in the solution $x$ by a quantity that depends on $A$ alone.

Throughout the chapter $\norm{x}$ is the Euclidean norm of $x \in \C^n$ and $\norm{A} = \max_{\norm{x} = 1}\norm{Ax}$ the induced spectral norm, which equals the largest singular value $\sigma_1(A)$ (norms from singular values, chapter 4). The singular values of a square matrix are written $\sigma_1 \ge \dots \ge \sigma_n \ge 0$, and $\sigma_{\min} = \sigma_n$. As elsewhere in the guide, $A^\T$ is the transpose, $A^*$ the conjugate transpose, $e_i$ the $i$-th standard basis vector, $I$ the identity and $\Lambda(A)$ the spectrum of $A$, its set of eigenvalues.

The condition number of an invertible matrix $A$ is $\kappa(A) = \norm{A}\,\norm{A^{-1}}$.

Let $A \in \C^{n\times n}$ be invertible. (i) $\kappa(A) = \sigma_1/\sigma_n \ge 1$, and $\kappa(A) = 1$ if and only if $A$ is a nonzero multiple of a unitary matrix. (ii) $\kappa(cA) = \kappa(A)$ for every scalar $c \neq 0$, and $\kappa(UAV) = \kappa(A)$ for all unitary $U$ and $V$.

Proof. (i) Let $A = U_A\Sigma V_A^*$ be a singular value decomposition, with $U_A$, $V_A$ unitary and $\Sigma = \diag(\sigma_1, \dots, \sigma_n)$, $\sigma_n > 0$. Then $A^{-1} = V_A\Sigma^{-1}U_A^*$ is a singular value decomposition with singular values $1/\sigma_i$, so $\norm{A^{-1}} = 1/\sigma_n$ and $\kappa(A) = \sigma_1/\sigma_n \ge 1$. Equality holds exactly when all $\sigma_i$ equal some $s > 0$, that is, when $A = s\,U_AV_A^*$ with $U_AV_A^*$ unitary; conversely every singular value of $cQ$, for $Q$ unitary, is $\abs{c}$. (ii) $cA$ has singular values $\abs{c}\sigma_i$, and $UAV = (UU_A)\,\Sigma\,(V^*V_A)^*$ is a singular value decomposition with the same $\Sigma$.

Let $A$ be invertible, $Ax = b$ and $b \neq 0$.

  1. If $A(x + \delta x) = b + \delta b$, then $\dfrac{\norm{\delta x}}{\norm{x}} \le \kappa(A)\,\dfrac{\norm{\delta b}}{\norm{b}}$, and equality holds for suitable $b$ and $\delta b$.
  2. If $(A + \delta A)(x + \delta x) = b$ and $\norm{A^{-1}}\norm{\delta A} < 1$, then $\dfrac{\norm{\delta x}}{\norm{x}} \le \dfrac{\kappa(A)\,\norm{\delta A}/\norm{A}}{1 - \kappa(A)\,\norm{\delta A}/\norm{A}}$.

(2) Subtracting $Ax = b$ gives $A\,\delta x = -\delta A\,(x + \delta x)$, hence $\norm{\delta x} \le \norm{A^{-1}}\norm{\delta A}(\norm{x} + \norm{\delta x})$; solve for $\norm{\delta x}$. Four probes. A unitary $Q$ has $\kappa(Q) = 1$: errors are not amplified at all. Scaling changes nothing, $\kappa(cA) = \kappa(A)$ for $c \neq 0$. Both are . The diagonal matrix $\diag(1, \delta)$ with $0 < \delta < 1$ has $\kappa = 1/\delta$, and an error in the second entry of $b$ is divided by $\delta$. Nearly dependent columns do the same in disguise: $A = \begin{bmatrix}1 & 1\\ 1 & 1+\delta\end{bmatrix}$ has determinant $\det A = \delta$ and $A^{-1} = \frac{1}{\delta}\begin{bmatrix}1+\delta & -1\\ -1 & 1\end{bmatrix}$, so changing $b = (2, 2+\delta)^\T$ by $(0, \eta)^\T$ moves the solution from $(1,1)^\T$ by $\frac{\eta}{\delta}(-1, 1)^\T$.

For invertible $A \in \C^{n\times n}$,

$$\min\{\norm{E} : A + E \text{ is singular}\} = \sigma_n(A) = \frac{1}{\norm{A^{-1}}},$$

equivalently

$$\min\Big\{\frac{\norm{E}}{\norm{A}} : A + E \text{ singular}\Big\} = \frac{1}{\kappa(A)}.$$

Proof. If $\norm{E} < \sigma_n$, then for every unit vector $x$, $\norm{(A+E)x} \ge \norm{Ax} - \norm{Ex} \ge \sigma_n - \norm{E} > 0$, so $A + E$ is injective. Conversely, with $Av_n = \sigma_n u_n$ for unit singular vectors $u_n, v_n$, the matrix $E = -\sigma_n u_n v_n^*$ has $\norm{E} = \sigma_n$ and $(A + E)v_n = 0$.

"A small residual means an accurate solution" is false. For an approximate solution $\hat x$ with residual $r = b - A\hat x$, the error is $x - \hat x = A^{-1}r$, and gives only $\norm{x - \hat x}/\norm{x} \le \kappa(A)\norm{r}/\norm{b}$. In the last probe, $\hat x = (1,1)^\T + \frac{\eta}{\delta}(-1,1)^\T$ has residual of norm $\eta$ but error of norm $\sqrt2\,\eta/\delta$: with $\delta = \eta = 10^{-6}$, a residual of $10^{-6}$ hides an error of $1.4$.

Invariants and an equivalence. $\kappa$ is unchanged by unitary factors on either side, $\kappa(UAV) = \kappa(A)$, and by scaling (). By it is the reciprocal of the relative distance from $A$ to the nearest singular matrix: being ill-conditioned and being close to singular, relative to the size of $A$, are the same property. The determinant does not measure it (chapter 1): $\det(\eps I_n) = \eps^n$ while $\kappa(\eps I_n) = 1$.

Conditioning belongs to the problem; stability belongs to the algorithm. An algorithm for $Ax = b$ is backward stable if its computed solution $\hat x$ solves a perturbed system $(A + \delta A)\hat x = b + \delta b$ exactly, with $\norm{\delta A} \le \eta\norm{A}$ and $\norm{\delta b} \le \eta\norm{b}$ for some $\eta$ of the order of the unit roundoff $u = 2^{-53} \approx 1.1\times 10^{-16}$ of double precision.

Let $A$ be invertible, $Ax = b$ with $b \neq 0$, and let $\hat x$ satisfy $(A + \delta A)\hat x = b + \delta b$, where $\norm{\delta A} \le \eta\norm{A}$, $\norm{\delta b} \le \eta\norm{b}$ and $\kappa(A)\,\eta < 1$. Then

$$\frac{\norm{\hat x - x}}{\norm{x}} \;\le\; \frac{2\,\kappa(A)\,\eta}{1 - \kappa(A)\,\eta}.$$

Proof. Write $\hat x = x + \delta x$. Subtracting $Ax = b$ gives $A\,\delta x = \delta b - \delta A\,x - \delta A\,\delta x$. Apply $A^{-1}$, take norms and use $\norm{\delta b} \le \eta\norm{b} \le \eta\norm{A}\norm{x}$:

$$\norm{\delta x} \le \norm{A^{-1}}\,\eta\norm{A}\,\big(2\norm{x} + \norm{\delta x}\big) = \kappa(A)\,\eta\,\big(2\norm{x} + \norm{\delta x}\big);$$

solve for $\norm{\delta x}$.

As a rule of thumb, a backward stable solver therefore returns about $16 - \log_{10}\kappa(A)$ correct digits: with $\eta$ a modest multiple of $u$, bounds the relative error by a quantity of order $\kappa(A)\,u$. Householder QR is backward stable; Gaussian elimination with partial pivoting is backward stable in practice, though not for every matrix (Trefethen and Bau, lectures 12–16 and 22).

Hermitian matrices: Weyl's inequality and the gap

$A$ and $E$ are Hermitian $n\times n$ matrices ($A = A^*$, where $A^*$ is the conjugate transpose). Their eigenvalues are real (Hermitian basics, chapter 4) and ordered, $\lambda_1(A) \ge \dots \ge \lambda_n(A)$, and $A$ has an orthonormal basis of eigenvectors (the spectral theorem for normal matrices, chapter 4). Recall the Courant–Fischer characterization (chapter 4): $\lambda_k(A) = \max_{\dim \mathcal S = k}\ \min_{x \in \mathcal S,\, \norm{x} = 1} x^*Ax$, the maximum taken over subspaces $\mathcal S \subseteq \C^n$ of dimension $k$.

Bound the motion of each eigenvalue, and the rotation of each eigenvector, by the size of the perturbation $E$.

For Hermitian $A$ and $E$ and every $k$,

$$\lambda_k(A) + \lambda_n(E) \;\le\; \lambda_k(A + E) \;\le\; \lambda_k(A) + \lambda_1(E),$$

hence

$$\abs{\lambda_k(A+E) - \lambda_k(A)} \le \norm{E}.$$

Proof. For every unit vector $x$, $x^*(A+E)x = x^*Ax + x^*Ex$ with $\lambda_n(E) \le x^*Ex \le \lambda_1(E)$. Taking the minimum over unit $x$ in a fixed subspace $\mathcal S$ and then the maximum over $\dim\mathcal S = k$ preserves both inequalities, and Courant–Fischer turns the two sides into $\lambda_k(A+E)$ and $\lambda_k(A) + \lambda_{1}(E)$ or $\lambda_k(A) + \lambda_n(E)$. For Hermitian $E$, $\norm{E} = \max(\abs{\lambda_1(E)}, \abs{\lambda_n(E)})$, because the singular values of a normal matrix are the moduli of its eigenvalues (eigenvalues and singular values, chapter 4).

The extreme case $E = \eps I$ shifts every eigenvalue by exactly $\eps$, so the bound cannot be improved. A positive semidefinite $E$ can only move eigenvalues up, since then $\lambda_n(E) \ge 0$ (Weyl's inequality and monotonicity, chapter 4). By , eigenvalues of Hermitian matrices are Lipschitz functions of the matrix, with constant 1 in the spectral norm: perfectly conditioned in absolute terms, however close together they are.

Let $A$ be Hermitian with orthonormal eigenvectors $v_1, \dots, v_n$ for $\lambda_1 \ge \dots \ge \lambda_n$, and let $\lambda_k$ be simple. Let $\hat A = A + E$ be Hermitian and $\hat v$ a unit eigenvector, $\hat A\hat v = \hat\lambda\hat v$. If $\delta = \min_{i \neq k}\abs{\hat\lambda - \lambda_i} > 0$, the angle $\theta \in [0, \pi/2]$ between $\hat v$ and $v_k$, defined by $\cos\theta = \abs{v_k^*\hat v}$, satisfies

$$\sin\theta \;\le\; \frac{\norm{E\hat v}}{\delta} \;\le\; \frac{\norm{E}}{\delta}.$$

If $\hat\lambda = \lambda_k(\hat A)$ and $\norm{E} < g$, where $g = \min_{i\neq k}\abs{\lambda_i - \lambda_k}$ is the gap, then $\sin\theta \le \norm{E}/(g - \norm{E})$.

Proof. Expand $\hat v = \sum_i c_i v_i$, so that $\sum_i \abs{c_i}^2 = 1$ and $\sin^2\theta = 1 - \abs{c_k}^2$, which equals $\sum_{i\neq k}\abs{c_i}^2$. The residual of $\hat v$ for $A$ is $r = A\hat v - \hat\lambda\hat v = -E\hat v$, and $r = \sum_i c_i(\lambda_i - \hat\lambda)v_i$. By orthonormality,

$$\norm{E\hat v}^2 = \sum_i \abs{c_i}^2\abs{\lambda_i - \hat\lambda}^2 \;\ge\; \delta^2\sum_{i\neq k}\abs{c_i}^2 = \delta^2\sin^2\theta.$$

For the last statement, Weyl gives $\abs{\hat\lambda - \lambda_k} \le \norm{E}$, so $\delta \ge g - \norm{E}$.

Without a gap there is no eigenvector stability. Take $A = \diag(1, 1+\delta)$ and $E = \eps\begin{bmatrix}0 & 1\\ 1 & 0\end{bmatrix}$ with $0 < \delta \ll \eps$. The eigenvalues of $A + E$ are $1 + \frac{\delta}{2} \pm \sqrt{\delta^2/4 + \eps^2}$, within $\eps$ of $1$ and $1 + \delta$ as Weyl promises, but its eigenvectors make an angle $\theta$ with $e_1$ where $\abs{\tan 2\theta} = 2\eps/\delta$. As $\delta/\eps \to 0$ they approach $(1, \pm 1)^\T/\sqrt2$: a perturbation of size $\eps$ turns the eigenvectors by nearly $45^\circ$. The scale is set by the gap, not by the size of $A$.

The same argument handles invariant subspaces, with the single angle replaced by the canonical angles between two subspaces and the residual equation replaced by a Sylvester equation.

Let $A$ and $\hat A = A + E$ be Hermitian $n\times n$ matrices and $1 \le k < n$. Let $\hat V \in \C^{n\times k}$ have orthonormal columns with $\hat A\hat V = \hat V\hat\Lambda$, where $\hat\Lambda = \hat V^*\hat A\hat V$, and let $\begin{bmatrix}V_1 & V_2\end{bmatrix}$ be unitary with $V_1 \in \C^{n\times k}$ and $AV_2 = V_2\Lambda_2$ for a diagonal matrix $\Lambda_2$. The canonical angles $\theta_1, \dots, \theta_k \in [0, \pi/2]$ between the column spaces (ranges) $\Range(\hat V)$ and $\Range(V_1)$ are defined by: $\cos\theta_1, \dots, \cos\theta_k$ are the singular values of $V_1^*\hat V$. Write $\sin\Theta = \diag(\sin\theta_1, \dots, \sin\theta_k)$ and $\norm{M}_F = \big(\sum_{i,j}\abs{m_{ij}}^2\big)^{1/2}$ for the Frobenius norm.

  1. If every eigenvalue of $\Lambda_2$ is at distance at least $\delta > 0$ from every eigenvalue of $\hat\Lambda$, then $\norm{\sin\Theta}_F = \norm{V_2^*\hat V}_F \le \norm{E\hat V}_F/\delta$.
  2. If the eigenvalues of $\hat\Lambda$ lie in an interval $[a, b]$ and those of $\Lambda_2$ lie outside $(a - \delta, b + \delta)$, with $\delta > 0$, then $\norm{\sin\Theta} = \max_j\sin\theta_j \le \norm{E\hat V}/\delta$.

Proof. Since $\begin{bmatrix}V_1 & V_2\end{bmatrix}$ is unitary, $I = \hat V^*\hat V = (V_1^*\hat V)^*(V_1^*\hat V) + (V_2^*\hat V)^*(V_2^*\hat V)$, so the eigenvalues of $(V_2^*\hat V)^*(V_2^*\hat V)$ are $1 - \cos^2\theta_j = \sin^2\theta_j$; this gives both equalities. The residual of $\hat V$ for $A$ is $A\hat V - \hat V\hat\Lambda = -E\hat V$. Multiplying it on the left by $V_2^*$ and using $V_2^*A = \Lambda_2V_2^*$ ($A$ is Hermitian and $\Lambda_2$ real), $X = V_2^*\hat V$ solves the Sylvester equation

$$\Lambda_2X - X\hat\Lambda = Y,\qquad Y = -V_2^*E\hat V,$$

and $\norm{Y}_F \le \norm{E\hat V}_F$, $\norm{Y} \le \norm{E\hat V}$ because $V_2^*$ has orthonormal rows. (1) Diagonalize the Hermitian matrix $\hat\Lambda = WDW^*$ with $W$ unitary and $D = \diag(\mu_1, \dots, \mu_k)$. Then $Z = XW$ satisfies $\Lambda_2Z - ZD = YW$, entry by entry $(\lambda_{2,i} - \mu_j)\,z_{ij} = (YW)_{ij}$ with $\abs{\lambda_{2,i} - \mu_j} \ge \delta$, where $\lambda_{2,i}$ are the diagonal entries of $\Lambda_2$. Hence $\norm{X}_F = \norm{Z}_F \le \norm{YW}_F/\delta = \norm{Y}_F/\delta$. (2) Let $c = (a + b)/2$ and $r = (b - a)/2$, so that $\norm{\hat\Lambda - cI} \le r$ and $\norm{(\Lambda_2 - cI)^{-1}} \le 1/(r + \delta)$. Rewriting the equation as $X = (\Lambda_2 - cI)^{-1}\big(Y + X(\hat\Lambda - cI)\big)$ and substituting it into itself $N$ times writes $X$ as the sum of the terms $(\Lambda_2 - cI)^{-j-1}\,Y\,(\hat\Lambda - cI)^j$ for $j < N$ and the remainder $(\Lambda_2 - cI)^{-N}X(\hat\Lambda - cI)^N$, whose norm is at most $\norm{X}\big(r/(r + \delta)\big)^N \to 0$. So $\norm{X} \le \norm{Y}\sum_{j\ge0}r^j/(r + \delta)^{j+1} = \norm{Y}/\delta$.

For $k = 1$, part 1 is the first inequality of . Davis and Kahan (1970); Bhatia, Matrix Analysis, ch. VII, proves part 2 for every unitarily invariant norm.

Non-normal matrices: Bauer–Fike, condition numbers and Jordan blocks

Drop the Hermitian assumption and the picture changes. $A = \begin{bmatrix}1 & 1000\\ 0 & 1\end{bmatrix}$ has the double eigenvalue $1$. Changing its $(2,1)$ entry from $0$ to $10^{-3}$, a perturbation of norm $10^{-3}$, gives the characteristic polynomial $(\lambda - 1)^2 - 1$ and eigenvalues $0$ and $2$. The eigenvalues moved a thousand times farther than the entries.

A matrix is normal if $A^*A = AA^*$; equivalently it is unitarily diagonalizable (normal matrices, chapter 4). Hermitian, skew-Hermitian and unitary matrices are normal (chapter 4); the matrix above is not.

Let $A = V\Lambda V^{-1}$ with $\Lambda = \diag(\lambda_1, \dots, \lambda_n)$, and let $E \in \C^{n\times n}$ be arbitrary. Every eigenvalue $\mu$ of $A + E$ satisfies

$$\min_i\,\abs{\mu - \lambda_i} \;\le\; \kappa(V)\,\norm{E},\qquad \kappa(V) = \norm{V}\norm{V^{-1}}.$$

Proof. If $\mu \in \Lambda(A)$ there is nothing to prove. Otherwise $\mu I - A$ is invertible and $\mu I - A - E = (\mu I - A)\big(I - (\mu I - A)^{-1}E\big)$ is singular, so $\norm{(\mu I - A)^{-1}E} \ge 1$ (if $\norm{F} < 1$ then $I - F$ is invertible, by the Neumann series of chapter 5). Since $(\mu I - A)^{-1} = V(\mu I - \Lambda)^{-1}V^{-1}$ and $\norm{(\mu I - \Lambda)^{-1}} = 1/\min_i\abs{\mu - \lambda_i}$ (the norm of a diagonal matrix is its largest entry in modulus), we get $1 \le \kappa(V)\norm{E}/\min_i\abs{\mu - \lambda_i}$.

If $A \in \C^{n\times n}$ is normal, then for every $E \in \C^{n\times n}$ each eigenvalue of $A + E$ lies within $\norm{E}$ of $\Lambda(A)$.

Proof. A normal matrix is unitarily diagonalizable, $A = U\Lambda U^*$ with $U$ unitary. Apply with $V = U$: unitary matrices preserve the norm of every vector, so $\norm{U} = \norm{U^{-1}} = \norm{U^*} = 1$ and $\kappa(U) = 1$.

A nonzero $y \in \C^n$ with $y^*A = \lambda y^*$ is a left eigenvector of $A$ for $\lambda$ (equivalently $A^*y = \bar\lambda y$, where the bar denotes complex conjugation). For a simple eigenvalue $\lambda$ with right eigenvector $x$ and left eigenvector $y$, the eigenvalue condition number is $\kappa(\lambda) = \dfrac{\norm{x}\,\norm{y}}{\abs{y^*x}}$, the reciprocal cosine of the angle between $x$ and $y$.

Let $\lambda$ be a simple eigenvalue of $A$ with right and left eigenvectors $x$, $y$. Then $y^*x \neq 0$, and for every $E$ the matrix $A + tE$ has an eigenvalue $\lambda(t)$, analytic near $t = 0$, with $\lambda(0) = \lambda$ and

$$\lambda'(0) = \frac{y^*Ex}{y^*x},\qquad\text{so}\qquad \abs{\lambda'(0)} \le \kappa(\lambda)\,\norm{E},$$

with equality for $E = yx^*/(\norm{x}\norm{y})$.

Proof. Because $\lambda$ is simple its Jordan block is $1\times 1$ (Jordan normal form, chapter 3), so $\Null((A - \lambda I)^2) = \Null(A - \lambda I)$ and $\C^n$ is the direct sum $\Null(A - \lambda I) \oplus \Range(A - \lambda I)$ of a null space and a range: a vector in both is $(A - \lambda I)w$ with $(A - \lambda I)^2w = 0$, hence zero, and the dimensions add up to $n$ by rank–nullity. The relation $y^*(A - \lambda I) = 0$ says $y \perp \Range(A - \lambda I)$; if also $y \perp x$, then $y$ is orthogonal to all of $\C^n$, impossible. The characteristic polynomial $\det(zI - A - tE)$ is a polynomial in $z$ and $t$ whose $z$-derivative does not vanish at the simple root $\lambda$ for $t = 0$, so by the implicit function theorem that root continues to a root $\lambda(t)$ analytic in $t$, and an eigenvector $x(t)$ can be chosen differentiably as well (Horn and Johnson, ch. 6). Differentiating $(A + tE)x(t) = \lambda(t)x(t)$ at $t = 0$ gives $Ex + Ax' = \lambda' x + \lambda x'$; multiplying by $y^*$ and using $y^*A = \lambda y^*$ cancels the $x'$ terms and leaves $y^*Ex = \lambda'\,y^*x$. The bound is Cauchy–Schwarz, $\abs{y^*Ex} \le \norm{y}\norm{E}\norm{x}$, and the stated $E$ has norm $1$ and gives $y^*Ex = \norm{x}\norm{y}$.

Let $A = \begin{bmatrix}-1 & w\\ 0 & -2\end{bmatrix}$ with a coupling $w \ge 0$; this matrix returns in . For $\lambda_1 = -1$: $x_1 = e_1$ and $y_1 = (1, w)^\T$. For $\lambda_2 = -2$: $x_2 = (-w, 1)^\T$ and $y_2 = e_2$. Both eigenvalues have $\kappa(\lambda_i) = \sqrt{1 + w^2}$, and the matrix of unit eigenvectors has $\kappa(V) = \sqrt{(1+c)/(1-c)}$ with $c = w/\sqrt{1+w^2}$, about $2w$ for large $w$. For $w = 0$ the matrix is diagonal and both numbers equal 1.

For $\eps > 0$ the matrix

$$J_n(0) + \eps\, e_n e_1^\T = \begin{bmatrix}0 & 1 & & \\ & \ddots & \ddots & \\ & & 0 & 1\\ \eps & & & 0\end{bmatrix}$$

has characteristic polynomial $z^n - \eps$, hence the $n$ distinct eigenvalues $\mu_k = \eps^{1/n}e^{2\pi i k/n}$, $k = 0, \dots, n-1$ (here $i$ is the imaginary unit, which engineering texts write $j$), all at distance $\eps^{1/n}$ from the eigenvalue $0$ of $J_n(0)$, although $\norm{\eps e_ne_1^\T} = \eps$.

Proof. Expand $\det(zI - J_n(0) - \eps e_ne_1^\T)$ along the first column, which has $z$ in row 1 and $-\eps$ in row $n$. The minor of the $(1,1)$ entry is upper triangular with diagonal $z$, contributing $z\cdot z^{n-1}$. The minor of the $(n,1)$ entry is lower triangular with diagonal $-1$, so it equals $(-1)^{n-1}$, and with the cofactor sign $(-1)^{n+1}$ the contribution is $-\eps(-1)^{n+1}(-1)^{n-1} = -\eps$.

"Eigenvalues are continuous, so small perturbations move them a little" is true only in a weak sense: they are continuous, but with a modulus of continuity as poor as $\norm{E}^{1/n}$ (). For $n = 16$ and $\eps = 10^{-16}$, about the unit roundoff, moves the eigenvalues of $J_{16}(0)$ by $10^{-1}$: an amplification of $10^{15}$. The eigenvectors behave worse still: $J_n(0)$ has the single eigenvector $e_1$, while the perturbed matrix has $n$ independent eigenvectors $(1, \mu_k, \mu_k^2, \dots, \mu_k^{n-1})^\T$, all of which collapse onto $e_1$ as $\eps \to 0$. Consistently with , the defective eigenvalue has $y^*x = 0$: its right eigenvector is $e_1$ and its left eigenvector is $e_n$.

The corner perturbation is not special. To leading order only the bottom-left entry of a perturbation matters, and its $n$-th root is taken.

Let $n \ge 2$ and let $E \in \C^{n\times n}$ have bottom-left entry $E_{n1} = e_n^\T Ee_1 \neq 0$, and let $c$ be a fixed $n$-th root of $E_{n1}$. As $\eps \to 0^+$ the eigenvalues of $J_n(0) + \eps E$ can be numbered so that

$$\mu_k(\eps) = c\,\eps^{1/n}e^{2\pi ik/n} + O(\eps^{2/n}),\qquad k = 0, \dots, n-1.$$

In particular $\abs{\mu_k(\eps)} = \abs{E_{n1}}^{1/n}\eps^{1/n}\big(1 + O(\eps^{1/n})\big)$, and $\abs{E_{n1}} \le \norm{E}$.

Pseudospectra

Replace the spectrum by a set that moves continuously with $A$, that shows where eigenvalues can go under perturbations of a given size, and that controls functions of $A$ such as $e^{tA}$.

For $z \in \C$ outside the spectrum $\Lambda(A)$ the resolvent is $R(z) = (zI - A)^{-1}$; set $\norm{R(z)} = \infty$ for $z \in \Lambda(A)$. For $\eps > 0$ the $\eps$-pseudospectrum is

$$\Lambda_\eps(A) = \{z \in \C : \norm{(zI - A)^{-1}} > 1/\eps\}.$$

Trefethen and Embree write $\sigma(A)$ for the spectrum and $\sigma_\eps(A)$ for the pseudospectrum. This guide keeps $\sigma$ for singular values and writes $\Lambda(A)$ and $\Lambda_\eps(A)$.

For $A \in \C^{n\times n}$ and $\eps > 0$ the following four sets are equal:

  1. $\{z : \norm{(zI - A)^{-1}} > 1/\eps\}$;
  2. $\{z : z \in \Lambda(A + E) \text{ for some } E \text{ with } \norm{E} < \eps\}$;
  3. $\{z : \norm{(A - zI)v} < \eps \text{ for some unit vector } v\}$, the points with an $\eps$-pseudo-eigenvector;
  4. $\{z : \sigma_{\min}(zI - A) < \eps\}$.

Proof. (1) and (4) agree because $\norm{(zI-A)^{-1}} = 1/\sigma_{\min}(zI - A)$ (norms from singular values, chapter 4), both sides being infinite on $\Lambda(A)$. (4) implies (3): take $v$ the right singular vector for $\sigma_{\min}$. (3) implies (2): with $r = (A - zI)v$, the rank-one matrix $E = -rv^*$ has $\norm{E} = \norm{r} < \eps$ and $(A + E)v = Av - r = zv$. (2) implies (4): if $(A + E)v = zv$ with $\norm{v} = 1$, then $(zI - A)v = Ev$ and $\sigma_{\min}(zI - A) \le \norm{Ev} \le \norm{E} < \eps$.

The numerical range and the abscissas

The numerical range (field of values) of $A \in \C^{n\times n}$ is $W(A) = \{x^*Ax : x \in \C^n,\ \norm{x} = 1\}$, the set of all Rayleigh quotients.

Let $A \in \C^{n\times n}$ and let $H = \frac12(A + A^*)$ be its Hermitian part.

  1. $W(A)$ is compact and convex (Toeplitz–Hausdorff theorem).
  2. $\Lambda(A) \subseteq W(A)$.
  3. If $A$ is normal, $W(A)$ is the convex hull of $\Lambda(A)$; if $A$ is Hermitian, $W(A) = [\lambda_n, \lambda_1]$.
  4. $\Re(x^*Ax) = x^*Hx$, so $\max \Re W(A) = \lambda_{\max}(H)$.
  5. $W(U^*AU) = W(A)$ for unitary $U$, but in general $W(S^{-1}AS) \neq W(A)$ for invertible $S$.

Proof. Compactness: $W(A)$ is the continuous image of the unit sphere. (2) If $Ax = \lambda x$ with $\norm{x} = 1$, then $x^*Ax = \lambda$. (3) For $A = U\Lambda U^*$ and $z = U^*x$, $x^*Ax = \sum_i \abs{z_i}^2\lambda_i$, a convex combination with arbitrary weights $\abs{z_i}^2 \ge 0$ summing to 1. And $J_2(0)$ is similar to $sJ_2(0)$ for every $s \neq 0$ (conjugate by $\diag(1, s)$), whose numerical range is the disk of radius $\abs{s}/2$: similarity can make $W$ as large as we like. This is the point: $W(A)$ carries metric information that similarity invariants cannot.

The spectral abscissa is $\alpha(A) = \max\Re\Lambda(A)$, the numerical abscissa is $\omega(A) = \max\Re W(A)$, which equals $\lambda_{\max}\big(\frac12(A + A^*)\big)$ by part 4 of , and the $\eps$-pseudospectral abscissa is $\alpha_\eps(A) = \sup\Re\Lambda_\eps(A)$.

For $A \in \C^{n\times n}$ and $\eps > 0$, $\alpha(A) \le \omega(A)$ and $\alpha(A) + \eps \le \alpha_\eps(A)$. If $A$ is normal, both are equalities: $\omega(A) = \alpha(A)$ and $\alpha_\eps(A) = \alpha(A) + \eps$.

Proof. $\Lambda(A) \subseteq W(A)$, and for normal $A$ the set $W(A)$ is the convex hull of $\Lambda(A)$, whose largest real part is attained at an eigenvalue (parts 2 and 3 of ). Likewise $\Lambda(A) + \Delta_\eps \subseteq \Lambda_\eps(A)$, with equality for normal $A$ (part 3 of ), and $\sup\Re\big(\Lambda(A) + \Delta_\eps\big) = \alpha(A) + \eps$.

For every $\eps > 0$, $\Lambda_\eps(A) \subseteq W(A) + \Delta_\eps$; in particular $\alpha_\eps(A) \le \omega(A) + \eps$.

Proof. For $z \in \Lambda_\eps(A)$ take a unit $v$ with $\norm{(A - zI)v} < \eps$ (definition 3 of ). Then $\abs{v^*Av - z} = \abs{v^*(A - zI)v} \le \norm{(A - zI)v} < \eps$, and $v^*Av \in W(A)$.

Transient growth

The solution of the linear differential equation $\dot x = Ax$ (where $\dot x = \dd x/\dd t$), $x(0) = x_0$, is $x(t) = e^{tA}x_0$, where $e^{tA}$ is the matrix exponential (existence and uniqueness, chapter 7). If every eigenvalue has negative real part, $x(t) \to 0$ (eigenvalue tests in continuous time, chapter 7). How large can $\norm{x(t)}$ become on the way, and which properties of $A$ decide it?

The quantity to control is $\norm{e^{tA}} = \max_{x_0 \neq 0}\norm{x(t)}/\norm{x_0}$, the worst amplification at time $t$; it is attained at the top right singular vector of $e^{tA}$ (norms from singular values, chapter 4). Two facts from chapter 7 are used: the eigenvalues of $e^{tA}$ are $e^{t\lambda_i}$ (properties of the exponential), and in a Jordan basis the entries of $e^{tA}$ are combinations of $t^je^{\lambda_it}$ (exponential of a Jordan block).

For every $A \in \C^{n\times n}$ and $t \ge 0$,

$$e^{t\alpha(A)} \;\le\; \norm{e^{tA}} \;\le\; e^{t\omega(A)}.$$

Moreover the right derivative at $t = 0$ of $\norm{e^{tA}}$ is $\omega(A)$, and $\lim_{t\to\infty}\frac1t\log\norm{e^{tA}} = \alpha(A)$. In particular $\omega(A)$ is the smallest $\beta$ with $\norm{e^{tA}} \le e^{\beta t}$ for all $t \ge 0$.

Proof. Lower bound: every induced norm dominates the spectral radius (chapter 5), and the eigenvalues of $e^{tA}$ are $e^{t\lambda_i}$, so $\norm{e^{tA}} \ge \max_i\abs{e^{t\lambda_i}} = e^{t\alpha}$. Upper bound: along $x(t) = e^{tA}x_0$, $\frac{\dd}{\dd t}\norm{x}^2 = \dot x^*x + x^*\dot x = x^*(A + A^*)x \le 2\omega\norm{x}^2$, so $e^{-2\omega t}\norm{x(t)}^2$ is nonincreasing and $\norm{x(t)} \le e^{\omega t}\norm{x_0}$. Initial slope: $e^{tA} = I + tA + O(t^2)$ and $\norm{I + tA}^2 = \lambda_{\max}\big(I + 2tH + t^2A^*A\big)$, which by is $1 + 2t\omega + O(t^2)$; hence $\norm{e^{tA}} = 1 + t\omega + O(t^2)$. Long-time rate: with a Jordan form $A = SJS^{-1}$, $\norm{e^{tA}} \le \kappa(S)\norm{e^{tJ}} \le c\,(1 + t^{n-1})e^{t\alpha}$, which together with the lower bound gives the limit. If $\norm{e^{tA}} \le e^{\beta t}$ for all $t \ge 0$, comparing slopes at $t = 0$ gives $\omega \le \beta$.

For $A = \begin{bmatrix}-1 & w\\ 0 & -2\end{bmatrix}$ the exponential is upper triangular,

$$e^{tA} = \begin{bmatrix}e^{-t} & w\,(e^{-t} - e^{-2t})\\ 0 & e^{-2t}\end{bmatrix},$$

(check that it satisfies $\frac{\dd}{\dd t}e^{tA} = Ae^{tA}$ and equals $I$ at $t = 0$). The off-diagonal entry $w(e^{-t} - e^{-2t})$ is maximal where $e^{-t} = 2e^{-2t}$, at $t = \ln 2$, with value $w/4$. Since $\abs{(e^{tA})_{12}} \le \norm{e^{tA}} \le \norm{e^{tA}}_F$ (for any matrix $M$, $\abs{m_{12}} = \abs{e_1^\T Me_2} \le \norm{M}$, and $\norm{M}^2 = \sigma_1^2 \le \sum_i\sigma_i^2 = \norm{M}_F^2$ by norms from singular values, chapter 4) and the diagonal entries are at most 1,

$$\frac{w}{4} \;\le\; \max_{t \ge 0}\norm{e^{tA}} \;\le\; \sqrt{\frac{w^2}{16} + 2},$$

so the peak is $w/4 + O(1/w)$, although $\alpha(A) = -1$. Here $\omega(A) = \frac12(-3 + \sqrt{1 + w^2})$, positive exactly when $w > 2\sqrt2$, and by that is exactly when $\norm{e^{tA}}$ exceeds 1 at some time $t \ge 0$. Computed numerically: for $w = 10$ the peak is $2.56$ at $t \approx 0.66$; for $w = 20$ it is $5.03$ at $t \approx 0.69$.

Let $A \in \C^{n\times n}$.

  1. $\norm{e^{tA}} > 1$ for some $t \ge 0$ if and only if $\omega(A) > 0$. If $\omega(A) > 0$ this already holds for all small $t > 0$; if $\omega(A) \le 0$, then $\norm{e^{tA}} \le 1$ for all $t \ge 0$.
  2. If $A$ is normal, $\norm{e^{tA}} = e^{t\alpha(A)}$ for all $t \ge 0$. Hence if $\alpha(A) \le 0$ and $\norm{e^{tA}} > 1$ for some $t \ge 0$, then $A$ is not normal.

Proof. (1) If $\omega(A) \le 0$, gives $\norm{e^{tA}} \le e^{t\omega(A)} \le 1$. If $\omega(A) > 0$, the same theorem gives right derivative $\omega(A) > 0$ at $t = 0$, where $\norm{e^{0A}} = 1$, so $\norm{e^{tA}} > 1$ for small $t > 0$. (2) With $A = U\Lambda U^*$ and $U$ unitary, $e^{tA} = Ue^{t\Lambda}U^*$ (properties of the exponential, chapter 7), so $\norm{e^{tA}} = \norm{e^{t\Lambda}} = \max_i\abs{e^{t\lambda_i}} = e^{t\alpha(A)}$ for $t \ge 0$, the norm of a diagonal matrix being its largest entry in modulus.

"Non-normality causes transient growth" is false as stated: by , non-normality is necessary for growth when $\alpha(A) \le 0$, but it is not sufficient. For $0 < w \le 2\sqrt2$ the matrix $A = \begin{bmatrix}-1 & w\\ 0 & -2\end{bmatrix}$ is not normal, since $(A^*A)_{11} = 1$ while $(AA^*)_{11} = 1 + w^2$, yet $\omega(A) = \frac12(-3 + \sqrt{1 + w^2}) \le 0$, so $\norm{e^{tA}} \le 1$ for all $t \ge 0$. Growth occurs exactly when the numerical range reaches into the open right half-plane, which here takes $w > 2\sqrt2$.

The Schur form exposes the mechanism. Every $A$ can be written $A = UTU^*$ with $U$ unitary and $T = D + N$ upper triangular (Schur triangularization, chapter 3), where $D$ is diagonal with the eigenvalues and $N$ is strictly upper triangular. In the coordinates $z = U^*x$ the dynamics $\dot z = Tz$ is a cascade: the last coordinate evolves alone, and each coordinate is driven by those below it. The eigenvalues are the self-loops, and they are the diagonal of $D$ whatever $N$ is: $N$ is a feedforward network that the spectrum cannot see. The $2\times 2$ example is already in Schur form: $\dot x_2 = -2x_2$, and the decaying signal $x_2$ is fed into $\dot x_1 = -x_1 + w x_2$ with gain $w$. The same structure underlies balanced amplification in networks of excitatory and inhibitory neurons (the two-population Schur form, chapter 13).

If $A = U(D + N)U^*$ is a Schur form, then $\norm{N}_F^2 = \norm{A}_F^2 - \sum_i\abs{\lambda_i}^2$, so $\operatorname{dep}(A) = \norm{N}_F$ does not depend on which Schur form is used; $A$ is normal if and only if $\operatorname{dep}(A) = 0$.

Proof. The Frobenius norm $\norm{A}_F$ (the square root of the sum of squared moduli of the entries) is unitarily invariant, so $\norm{A}_F^2 = \norm{D + N}_F^2 = \sum_i\abs{\lambda_i}^2 + \norm{N}_F^2$, because $D$ and $N$ occupy disjoint entries. If $N = 0$, $A$ is unitarily diagonalizable, hence normal; conversely a normal triangular matrix is diagonal (compare the $(1,1)$ entries of $T^*T$ and $TT^*$ and induct).

For every $\eps > 0$,

$$\sup_{t \ge 0}\norm{e^{tA}} \;\ge\; \frac{\alpha_\eps(A)}{\eps}.$$

Hence $\sup_{t\ge0}\norm{e^{tA}} \ge \mathcal K(A)$, where the Kreiss constant is

$$\mathcal K(A) = \sup_{\eps>0}\frac{\alpha_\eps(A)}{\eps} = \sup_{\Re z > 0}\,\Re z\,\norm{(zI - A)^{-1}}.$$

Conversely (the Kreiss matrix theorem), for $A \in \C^{n\times n}$,

$$\mathcal K(A) \;\le\; \sup_{t \ge 0}\norm{e^{tA}} \;\le\; e\,n\,\mathcal K(A).$$

Proof of the lower bound. Let $M = \sup_{t\ge0}\norm{e^{tA}}$; if $M = \infty$ there is nothing to prove, and if $M < \infty$ then $\alpha(A) \le 0$. For $\Re z > 0$ the Laplace transform gives $(zI - A)^{-1} = \int_0^\infty e^{-zt}e^{tA}\,\dd t$ (Laplace transform of the exponential, chapter 7), so $\norm{(zI - A)^{-1}} \le M\int_0^\infty e^{-t\Re z}\dd t = M/\Re z$. If moreover $z \in \Lambda_\eps(A)$, then $1/\eps < M/\Re z$, so $M > \Re z/\eps$; take the supremum over such $z$. The two formulas for $\mathcal K(A)$ agree because $z \in \Lambda_\eps(A)$ exactly when $\eps > 1/\norm{R(z)}$.

Upper bound: Trefethen and Embree, ch. 18, which also gives the version for powers, $\mathcal K(A) \le \sup_{k\ge0}\norm{A^k} \le e\,n\,\mathcal K(A)$ with $\mathcal K(A) = \sup_{\abs{z}>1}(\abs{z} - 1)\norm{(zI - A)^{-1}}$.

For every $A \in \C^{n\times n}$, $\mathcal K(A) \ge 1$. If $A$ is normal and $\alpha(A) \le 0$, then $\mathcal K(A) = \sup_{t\ge0}\norm{e^{tA}} = 1$.

Proof. For real $x > \norm{A}$, $x\,(xI - A)^{-1} = (I - A/x)^{-1}$ by the Neumann series, and its norm tends to 1 as $x \to \infty$; so $\mathcal K(A) \ge 1$. If $A$ is normal with $\alpha(A) \le 0$, part 2 of gives $\sup_t\norm{e^{tA}} = \sup_t e^{t\alpha(A)} = 1$, and the lower bound of gives $\mathcal K(A) \le 1$.

Let $\Gamma$ be a finite union of rectifiable closed curves of total length $L$ that encloses $\Lambda(A)$ once in the positive sense, with $\norm{(zI - A)^{-1}} \le 1/\eps$ on $\Gamma$ (for instance the boundary of $\Lambda_\eps(A)$). Then for $t \ge 0$,

$$\norm{e^{tA}} \;\le\; \frac{L}{2\pi\eps}\,\max_{z \in \Gamma} e^{t\Re z}.$$

Proof. The Cauchy integral $e^{tA} = \frac{1}{2\pi i}\oint_\Gamma e^{tz}(zI - A)^{-1}\dd z$ holds for any such contour (expand the resolvent in a Jordan basis and apply Cauchy's formula entry by entry). Bound the integrand by $e^{t\Re z}/\eps$ and the integral by its length.

With $\Gamma$ the boundary $\partial\Lambda_\eps(A)$, of length $L_\eps$, reads $\norm{e^{tA}} \le \frac{L_\eps}{2\pi\eps}e^{t\alpha_\eps(A)}$, so $\sup_{t\ge0}\norm{e^{tA}} \le L_\eps/(2\pi\eps)$ whenever $\alpha_\eps(A) \le 0$; in the other direction gives $\sup_{t\ge0}\norm{e^{tA}} \ge \alpha_\eps(A)/\eps$. As a rule of thumb, then, if some $\Lambda_\eps(A)$ lies in the left half-plane and its boundary is not much longer than $2\pi\eps$, the transient is small, and if $\Lambda_\eps(A)$ extends much farther than $\eps$ into the right half-plane, it is large (Trefethen and Embree, ch. 14–16). Merely reaching the imaginary axis forces nothing: for $A = -\eps I$ the closure of $\Lambda_\eps(A)$ touches it, yet $\norm{e^{tA}} = e^{-\eps t} \le 1$.

Three time scales, three sets. The start of the transient is governed by the numerical range, through the initial slope $\omega(A)$, and the end by the spectrum, through the rate $\alpha(A)$ (); the height of the hump in between is governed by the pseudospectra, through $\mathcal K(A)$, up to the factor $e\,n$ (). For normal matrices the three coincide: $\omega = \alpha$ and $\alpha_\eps = \alpha + \eps$ (), $\norm{e^{tA}} = e^{t\alpha}$ (), and $\mathcal K(A) = 1$ when $\alpha \le 0$ ().

Discrete time has the same structure, with $\rho(A)$ and $\norm{A}$ in the roles of $e^{\alpha}$ and $e^{\omega}$. For $x_{k+1} = Ax_k$, $\rho(A)^k \le \norm{A^k}$ (two-sided bounds, chapter 3) and $\norm{A^k} \le \norm{A}^k$ by submultiplicativity, with $\rho(A)$ the spectral radius; $\norm{A^k}^{1/k} \to \rho(A)$ (Gelfand's formula, chapter 3); and the pseudospectra bound transient growth of the powers through the Kreiss constant for powers in the source note after (Trefethen and Embree, ch. 16 and 18).

Trefethen, Trefethen, Reddy and Driscoll, "Hydrodynamic stability without eigenvalues" (Science 261, 1993), observed that the linearized operators of plane Couette and Poiseuille flow are strongly non-normal, so small disturbances can be amplified by large factors before they decay even when every eigenvalue is stable. They argued that this transient amplification, combined with nonlinear effects, offers a route to turbulence at Reynolds numbers where eigenvalue analysis predicts stability. The same lens applies to recurrent neural circuits whose connectivity is far from symmetric (chapter 13).

Self-check

  1. You solve $Ax = b$ in double precision with a backward stable method and $\kappa(A) = 10^8$. Roughly how many digits of $x$ are correct?

    Answer

    The relative error is of order $\kappa(A)\,u \approx 10^8 \times 10^{-16} = 10^{-8}$ (): about 8 correct digits. Rounding errors are not the problem; the sensitivity of the problem is.

  2. A Hermitian $A$ has eigenvalues $1, 2, 5$, and $E$ is Hermitian with $\norm{E} = 0.3$. Where can the eigenvalues of $A + E$ lie, and which eigenvector is best determined?

    Answer

    In $[0.7, 1.3]$, $[1.7, 2.3]$ and $[4.7, 5.3]$, one in each (). The eigenvector for $5$ has gap $3$, so $\sin\theta \le 0.3/2.7 \approx 0.11$; those for $1$ and $2$ have gap $1$, so only $\sin\theta \le 0.3/0.7 \approx 0.43$ ().

  3. Find the eigenvalues of $\begin{bmatrix}0 & 1\\ \eps & 0\end{bmatrix}$. Why does not apply at $\eps = 0$?

    Answer

    $\pm\sqrt{\eps}$, whose derivative in $\eps$ is infinite at $0$. The eigenvalue $0$ of $J_2(0)$ is not simple: its right eigenvector $e_1$ and left eigenvector $e_2$ satisfy $y^*x = 0$, so the quotient that defines $\kappa(\lambda)$ for simple eigenvalues is infinite, and the motion is of order $\eps^{1/2}$, not $\eps$ ().

  4. All eigenvalues of $A$ have negative real part, yet the pseudospectrum $\Lambda_{0.01}(A)$ contains the point $0.5$. What follows about $\norm{e^{tA}}$?

    Answer

    $\alpha_{0.01}(A) \ge 0.5$, so $\sup_{t\ge0}\norm{e^{tA}} \ge 0.5/0.01 = 50$ by : some initial condition is amplified at least fiftyfold before it decays.

  5. $A$ has all eigenvalues in the open left half-plane but $\omega(A) > 0$. Show that some solution of $\dot x = Ax$ grows at first.

    Answer

    Take $x_0$ a unit top eigenvector of $H = \frac12(A + A^*)$. Then $\frac{\dd}{\dd t}\norm{x}^2\big|_{t=0} = 2x_0^*Hx_0 = 2\omega(A) > 0$; this is part 1 of . The Euclidean norm does not decrease along every solution; chapter 7 finds a weighted norm that does (Lyapunov's theorem).
